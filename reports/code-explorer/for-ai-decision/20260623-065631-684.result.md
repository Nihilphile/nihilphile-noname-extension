## 1. AI 决策入口 / 核心文件

### 1.1 `ai` 主入口 & `Basic` 类

| 文件 | 路径 | 说明 |
|------|------|------|
| AI 主模块 | `noname/ai/index.js` | 导出 `ai`, `Basic`, `setAI`。ai 实例持有 `basic` 和对 `get` 的代理 |
| Basic 类 | `noname/ai/basic.js` | 核心三个方法：`chooseButton(check)` (L15-L71), `chooseCard(check)` (L79-L161), `chooseTarget(check)` (L167-L233) |

#### `Basic.chooseCard(check)` 执行逻辑 (L79-L161)：
1. 获取当前 event，检查 event.filterCard
2. 若 filterCard 不存在 → 直接返回 check() > 0
3. 进入 while(iwhile--) 循环（最多100次）：
   - 获取 selectCard 范围 range
   - 若 range[1] <= -1（无上限）→ 对已选 cards 取 check() 加权和
   - 调用 get.selectableCards() + get.skills() 获取可选列表
   - 对所有选项调用 check()，取最大值所在 index
   - 若 check(cards[ix]) <= 0 且非 forced → 返回 ok
   - 若选中项是技能字符串 → ui.click.skill()，递归 chooseCard
   - 否则添加 class "selected"，加入 ui.selected.cards

#### `Basic.chooseTarget(check)` 执行逻辑 (L167-L233)：
类似 chooseCard，从 get.selectableTargets() 获取目标列表，选中后调用 targets[ix].classList.add("selected")

**锚点搜索词**: `chooseTarget(check)`, `chooseCard(check)`, `class Basic`

#### 默认 ai/ai1/ai2 赋值（player.js）：
- `chooseToUse`: `ai1` 默认 = `get.cacheOrder` (player.js L5405), `ai2` 默认 = `get.cacheEffectUse` (L5408)

#### chooseToUse AI 执行流程（content.js L4561-L4608）：
1. 若 event.result == "ai" → 进入 AI 逻辑
2. 若 game.check() == ok → ui.click.ok()
3. 否则：ai.basic.chooseCard(event.ai1) || forced
   - 通过 → ai.basic.chooseTarget(event.ai2) || forced
   - 通过 → ui.click.ok(); event._aiexcludeclear = true
   - 失败 → 排除当前技能/卡牌后 redo()
   - 失败 → ui.click.cancel()

#### chooseBool AI 执行（content.js L7779-L7783）：
```
if (event.result == "ai") {
    if (event.ai) event.choice = event.ai(event.getParent(), player);
    event.result = { bool: event.choice };
}
```

## 4. 人机如何判断是否发动技能

### 4.1 技能触发决策流程（content.js L3479-L3678）

```
createTrigger(event, trigger, player)
│
├─ 技能不在玩家技能列表中？→ hidden/invisible 处理
├─ event.cancelled? → return
├─ info.forced? → {bool:true} 强制发动
├─ info.direct? → {bool:true} 不弹窗直接进入 content
├─ info.cost 是函数? → 执行 cost 事件
│   └─ frequent==true 或 (frequent=="check" && check()) → AI 自动执行
└─ 否则 → chooseBool 对话框
    ├─ frequentSkill=true → 自动 ui.click.ok() (L7745)
    ├─ ai = () => !check || check(trigger, player, ...)
    └─ 无 check → 默认 true (AI 选发动)
```

### 4.2 filter/content/cost/check/direct/frequent/forced 配合

| 字段 | 作用 | AI 行为 |
|------|------|---------|
| `filter(event, player)` | 判断时机是否匹配 | 过滤不满足的时机 |
| `check(trigger, player,...)` | 判断是否值得发动 | 作为 chooseBool 的 ai 函数；无则默认 true |
| `cost` | 发动代价函数 | frequent 时 AI 自动执行 |
| `content` | 发动后效果 | 无条件执行 |
| `forced: true` | 锁定技 | 自动发动 |
| `frequent: true` | 频繁技 | AI 自动选"是"（autoskilllist 可禁用） |
| `frequent: "check"` | check通过即频繁 | check() 为真时 AI 自动选是 |
| `direct: true` | 不询问直接发动 | AI 跳过对话框 |
| `locked` | 锁定技变体 | 同 forced |

## 6. AI 决策流程简图

```
                    AI Round Start
                   _status.auto = true
                          │
          ┌───────────────┴───────────────┐
          │                               │
          ▼                               ▼
  1. chooseToUse                   2. createTrigger
  (出牌阶段主循环)                  (事件触发→技能响应)
  ┌─────────────────┐             ┌─────────────────┐
  │ ai1(card)排序选牌│             │ forced? → 直接发动│
  │ ai2(target)选目标│             │ direct? → 直接发动│
  │ default: order + │             │ cost+frequent?    │
  │   effect_use     │             │   → AI自动执行    │
  └────────┬────────┘             │ else → chooseBool │
           │                       │  ai=check()|true  │
           ▼                       │  frequent→自动OK  │
  3. chooseToRespond              └────────┬────────┘
  (响应杀/闪等)                            │
  ┌─────────────────┐                      ▼
  │ ai(card)选牌     │             4. chooseBool
  │ hasSkillTag检查  │             event.ai(event,player)
  │ (respondSha等)   │             → {bool: choice}
  └─────────────────┘

  核心评分链:
  get.effect(target,card)
   = result.player * attitude(viewer,player)
   + result.target * attitude(viewer,target) * threat
   + 铁索传导修正 + HP/手牌修正

  get.attitude(from,to)
   = rawAttitude(from,to) [模式定义]
   + madness + modAttitudeFrom/To hooks

  get.order(item) → skill.ai.order → 出牌优先级
  get.value(card) → card.ai.value → 牌价值
  get.useful(card) → card.ai.useful → 牌有用度
```
