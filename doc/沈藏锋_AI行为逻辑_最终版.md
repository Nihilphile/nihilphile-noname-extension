# 沈藏锋 AI 行为逻辑（最终版）

日期：2026-10-03。状态：行为设计完成，经同一独立子代理两轮有规则依据的对抗审计并收束。范围：本次附图三技能、经典军争身份局。本文只约定玩家应该如何选择，不设计代码、不改技能。规则编号均见 [AI 规则依据](沈藏锋_AI规则依据.md)，自定义细则采用与本次图一致的项目契约 v1.5，不沿用旧版行为。

先读第 3—7 节即可得到主要决策；第 4.1、5.1、6.1 节处理审计重点；第 9 节是供以后人工检查的桌面场景。

## 1. 合格玩家应有的打法

沈藏锋是等待机会、把势转成高伤击杀或防御资源的爆发角色。它应该会忍刀，也应该会在机会消失前出刀；没杀死时，能够重新比较保势与活命，而不是为了维持三势不断自残。

三个技能构成一条资源循环：不以杀造成伤害，结束阶段加势并补杀；锁心在出牌结束用多余杀改善手牌、布置下一段连环；合适时以增伤杀削减敌方行动机会。击杀能无代价保势，但“对面会濒死”不等于“本刀免费”。

合格标准：有身份目标、有完整出刀计划、有失败预案；用公开信息推测防御与救援；能解释为什么这回合等待、为什么攻击这个起点、为什么弃势。它不以伤害数字最大或势数量最大作为获胜替代品。

## 2. 信息与看多远

允许看自己的牌、公开牌区、势和体力、横置状态、座次、明确公开的技能和身份、公开获得/展示的牌及之后的移动记录。其他人的暗手牌、暗身份、牌堆顺序不能直接读取。

曾看见对方有闪或桃，之后发生无法辨别具体牌的暗手牌移动，就要降低该牌仍在手中的置信度；不能通过引擎内部牌编号偷偷延长追踪能力。未知摸牌只有可能收益；不能为了补全计划，假定自己将摸到桃、敌人将无闪或盟友必定配合。

每次判断至少看完：本张牌的目标响应、直接与连环伤害、求救与死亡、拔刀选择、剩余合法出牌、锁心、弃牌、蓄势，以及到自己下一次行动前的重要敌我行动。更远的收益应折减；翻面或受乐不思蜀影响时更不能把“下回合出刀”当确定事件。

命中、救援分高／中／低置信度，并记录证据。例如空手且没有可替代闪的公开技能，比手牌很多且有八卦更容易命中；公开桃且尚未用掉是救援证据，手牌多只是可能性。对未知牌保留失败分支，不编造固定命中百分比。身份不明时按多种身份后果比较，尤其避免主公误杀忠臣。

## 3. 全局决策顺序

先删掉不合法的行动，保留等待作为真实候选，再依次比较：

1. 能否赢下本局，或避免对手马上获胜。
2. 是否会让自己或必须保护的主公承担明显致死风险。
3. 是否减少敌方下一轮关键行动、解除迫近威胁。
4. 敌我有效伤害与救援消耗、死亡奖惩、牌差。
5. 结束时防御、手牌上限、可用势、下一次可靠出刀窗口。

同等级选择资源较省、失败代价较小的计划。存在不确定分支时，同时比较顺利结局和合理的失败结局；高收益只有在对方完全配合时才成立的计划要降级。紧急保主或终局窗口可以接受明显资源损失。

失败分支需要有证据支持，不能把所有极端坏事一概当必然，否则会永远不敢出刀。终局和迫近败局优先，普通情况下保生存；忠臣或反贼的自损能明显改善阵营胜率时，不能被“自己绝不能掉血”的机械限制否决。

### 必须做完的决策节点

| 节点 | 可选行动与取消边界 | 要回答的问题 |
| --- | --- | --- |
| 本阶段计划 | 等待、准备后攻、直接攻、控牌、资源兑换 | 为什么比不出杀更好？ |
| 杀材料与目标 | 在真正合法的牌与目标集合中选；可不出 | 颜色、属性、命中、救援、全链和阵营结果如何？ |
| 武器询问 | 斧强中、青龙追杀、寒冰防伤等可放弃 | 新收益是否覆盖牌、体力、后续付款与友伤？ |
| 拔刀付款 | 无死亡时强制二选一，不能取消 | 此时的势和体力下，哪条路线更能活且有用？ |
| 锁心选牌 | 不发动，或一次选择需要重铸的手牌杀 | 换牌和铁索资格值得牺牲哪些具体杀？ |
| 锁心选人 | 重铸后按新状态选 0 至 X 人 | 新增横置与解链分别给谁带来收益？ |
| 弃牌与响应 | 合法保留、打出/使用；按窗口可拒绝响应 | 防御、救援与攻击种子哪个实际更紧迫？ |

强制选择缺乏收益证据时，0势选清0摸0；有势通常选择不额外失血的清势。可选行为无明确正收益时，可以停手、不重铸或不选铁索目标。这些是回退，不覆盖已确认的保主或终局收益。

## 4. 出杀、等待与先做准备

每个出牌阶段至少比较下列计划：

| 计划 | 采用理由 | 放弃理由 |
| --- | --- | --- |
| 等待蓄势 | 下一次势增长能跨越击杀/范围门槛，且自己和阵营能撑到那时 | 关键敌人会先行动，主公危险，或等待后未必有出牌窗口 |
| 拆防／补装备后出杀 | 减少闪、防具、转移的阻碍；武器或坐骑改善真实目标集合 | 拆狮子可能回复对方，准备成本过高，或准备反而破坏火伤起点 |
| 现在出刀 | 有可靠击杀、连环优势、保主需求，或有效削弱比再等更有价值 | 连环伤及自己/主公，目标防御太厚，失败后不能承受拔刀 |
| 出刀后弃势换牌 | 有合理即时伤害或逼闪收益，且缺乏防御，需要将势变成可用牌 | 摸牌多但大量会弃掉，或高势的可靠击杀窗口就在下一次行动 |
| 寒冰防伤控牌 | 命中后拆掉关键装备/手牌，比扣血更能降低迫近威胁；完全无杀伤时还可能保留蓄势 | 伤害能直接终局、失去装备反而救敌，或拆牌不能解除威胁 |

势数的默认倾向仅作起点：0 势出普通价值杀，未击杀选清 0 摸 0；1—2 势检查当回合是否已经够击杀，不机械攒到 3；3 势以上先检查强制火属性与全链风险，再考虑爆发；高势长期没有可靠窗口且防御不足时，允许弃势兑现。

每次等待都要说明多一势具体改变什么：从打不死到能跨救援门槛、从够不到到够得到、或从非属性杀到有安全火链。伤害已经溢出、全场已在范围内，而障碍仍是闪、减伤或转移时，继续攒势的边际收益很低；应考虑拆防、控牌、换牌或当前可用窗口，不能无限等待“更高势”。

使用非杀锦囊造成伤害通常不阻止蓄势，故可先以决斗、火攻等解决威胁或压低血线，但要计其手牌成本及连环风险。酒只在它确实跨越击杀/救援门槛或提高关键连环收益时优先，伤害已足够不浪费酒；少于 3 势仍可选原生属性杀发动连环。

出刀前必须写清三种结果：没有伤害；伤害但无人死亡；此刀至少造成一名武将死亡。前两种均要支付 G4，只有第一种仍可在本回合满足 G1。若已由杀造成伤害，后来第二刀被闪也不能恢复本回合的蓄势资格。

对有合理逼闪价值的敌人可试刀，但不得为了捡回杀故意打一张确定无效的杀。少数急缺防御时的弃势兑换，可以在完整比较等待和其他过牌后作为独立资源计划。

这里禁止的是把“捡回杀”单独当收益，不是禁止所有零伤出刀。比如高势、低体力、没有防御，现有杀因公开防具确定无效，等待只能加势补杀，出刀却可清势获得多张防御候选；若不存在更好的合法过牌、拆防或击杀路线，零伤兑换可以合理。必须说明兑换的是生存资源，计弃牌损耗和摸不到防御的失败风险。

### 4.1 寒冰：主动放弃伤害何时更聪明

寒冰是在杀将造成伤害时才有的选择，不是对未命中杀免费拆牌。比较两条现场分支：照常扣血，或防止此次伤害并依次拆牌。敌方连弩、关键防具或攻击材料构成迫近威胁，扣血又不足以击杀时，拆牌可能更能减少敌方行动能力。拆的是手牌/装备等规则允许对象，不把判定区牌加入寒冰可拆集合。[历史装备依据](https://gltjk.com/sanguosha/rules/card/equipment.html)

只要本回合最终没有任何自己使用的杀造成正数伤害，完全防伤路线保留G1资格。无人因此刀死亡，G4仍须缴；不是拆两牌就免拔刀。多目标或追杀中其他部分已有伤害时，寒冰只防住其中一次不能恢复G1。

拆白银狮子可能给敌人回血，应看当时体力；去连弩只能降低已知连杀能力，不能保证敌人随后摸牌毫无威胁。敌人有别的额外杀来源、伤害已能可靠击杀、要靠这份属性伤害启动有利连环，或控牌收益很小，就可能不发动寒冰。

## 5. 选目标与连环起点

先看其是否为合法目标，再看此刀是否生效、是否命中、伤害多少、是否被救回。裸伤按使用时势数计算，随后按实际装备技能修正。目标的体力等于伤害不代表死亡；救援缺口为伤害后达到 1 体力需要的回复量。

通常优先能威胁己方胜负、命中更可靠、救援更弱的敌人，兼顾其下一次行动顺序。卖血角色要按实际触发的收益扣分，不能把全部卖血武将一律不打；致死前仍有濒死技能，不保证跳过其全部收益。

火或雷杀对横置起点的价值是全场链条价值。检查每一个连环角色，包括自己、队友和身份未明者。不能只看指定的敌人，也不能将自己不在直接目标中误当安全。

起点不一定选最低血的人：空手、无有效防御的横置敌人可能比持闪敌人更容易启动；藤甲起点可能提高传导基数；狮子起点可能压低全链基数。传导目标不能用闪抵消那份传导伤害；各自仍能有防止、减伤或转移。不能在下游重复把拔刀的势加成加一遍。

青釭无视的是对应直接效果的防具交互，不能统一把链上所有防具删除；斧强行命中须计弃两牌，是否因此失去自身装备能力也需按实际时机重算。遇到版本特殊的转移或防具交互，查具体文本，不替所有版本作同一裁定。

按行动顺序处理求救、死亡和终局。主忠不能为保势牺牲主公；内奸不能在其他角色尚存活时让主公先死；反贼面对主公致死窗口应按实际终局优先，不为多杀几人拖延。

### 5.1 方天等多目标杀：逐人走完，不能只算一轮链

若合法获得额外直接目标，比较不同目标子集；不默认选满。方天须在选目标时满足最后手牌条件，不能靠预计之后摸牌、重铸或弃牌补出资格。目标合法确定后，中间摸牌不倒推取消先前资格。[历史装备依据](https://gltjk.com/sanguosha/rules/card/equipment.html)

按规则的效果顺序：先处理第一个直接目标的响应、伤害、濒死/死亡与该份连环，再更新所有角色的存活、体力、横置和救援牌，再处理下一直接目标。已经吃过传导的角色若仍是存活的直接目标，之后仍要结算其直接效果；解链不是取消指定目标。下游能用闪响应后来的直接效果，不能用闪抵消先前的链伤。[历史使用流程](https://gltjk.com/sanguosha/rules/flow/use.html)

例如2势原生火杀直接选横置A（3体力）和B（5体力），二者无响应、防具和救援，A先结算且死亡不终局：A吃3死，B先吃3链伤到2并重置，再吃自己的3直接伤害死亡。只直接选A则B通常留在2体力。每一步若有人被救、转移、完全防止、改变连环状态或令游戏结束，后面的路径必须相应更新；不是死记总伤害6。

同一张多目标杀按整张使用只结算一次G4，任一可归因死亡即可免该次选择；与青龙的多张杀不同。多目标中的第一次死亡后不能立刻提前做拔刀选择。

## 6. 拔刀二选一

选择发生在整张杀结算后，按现场重新判断，不提前承诺失血保势。实际没人死亡时：

1. 0 势默认清势，失血没有保势收益。
2. 1 体力默认清势，不为保势进入濒死；需要例外时必须有明确且规则允许的自救或团队终局理由。
3. 2 体力一般清势；3—4 体力也不是必保势，要看到下次行动前的风险和防御。
4. 当前势能在一个可说明的近期窗口形成击杀/必要范围，而失去 1 体力仍能安全存活时，保势可优于换牌。
5. 没有近期可用窗口、缺防御、敌方即将集火或摸牌能继续出牌改善局势时，偏向清势。

比较清势时摸牌真正留下和能立即使用的价值，不能把摸 X 张都算净收益。比较失血时计入更低的手牌上限、救援资源损耗和暴露的敌方攻击窗口；不把失去体力当卖血伤害。

主动出牌时可把已在手的桃、装备或防御准备纳入整段计划；失血后还能否主动回复，取决于是否仍能返回可用的出牌窗口。1体力保势即使能以已有桃/酒自救，也要计消耗及禁救效果，不默认队友会出桃；不能依赖选择保势后本不会发生的拔刀摸牌来救自己。回合外或阶段结束的窗口不能照搬主动回复。

无伤情况下：清势后若结束阶段仍到达且满足条件，通常重新得 1 势；保势失血则通常变成原势 +1。伤害未击杀情况下，两条路线均无 G1 增势。判定时仍须看阶段中断和后续其他杀的影响。

真实死亡免二选一不等于好事：己方连环死人虽然可能符合 G5，仍应在出刀前扣除阵营损失与身份惩罚。击杀免代价不能凭空创造额外出杀次数。

### 单张杀的结算账

以下假定是自己的回合、杀使用和结算时势均为S、没有中途改势，之后不再有杀伤，阶段未中断且游戏未终局。表中“本回合无杀伤”检查整个回合，包含本刀之前的普通杀、技能杀及嵌套追杀；不能只看本刀。摸牌价值另计使用与弃牌；表中“补杀”均须弃牌堆有可获得的杀。

| 此刀结果 | 拔刀后 | 结束阶段通常结果 |
| --- | --- | --- |
| 此刀无伤、清势 | 势0，摸S，本人体力不变 | 全回合无杀伤：势1，尽可能补1杀；此前已有杀伤：仍势0，不因蓄势补杀 |
| 此刀无伤、失血保势 | 势S，失去1体力 | 全回合无杀伤：势S+1，尽可能补1杀；此前已有杀伤：仍势S，不因蓄势补杀 |
| 有伤、无人死亡、清势 | 势0，摸S，本人体力不变 | 不因蓄势增势或补杀 |
| 有伤、无人死亡、失血保势 | 势S，失去1体力 | 不因蓄势增势或补杀 |
| 本刀伤害造成真实死亡 | 通常保势S，无G4摸牌/失血 | 已有杀伤，不因蓄势增势或补杀 |

在别人回合使用杀仍有G4，但不能在那个人回合末套用自己的蓄势返还。若结算前后势发生改变，伤害用本刀的使用时快照，清势摸牌用选择时的实际势，不能混用。

### 6.1 青龙、连弩与连续出刀：每张刀都重新算账

连弩等提供合法额外杀时，按每刀更新后的势、体力、手牌、范围、属性、目标防御与死亡信息重选。第一刀清势后，第二刀可能变弱、够不到目标或恢复成原本属性；第一刀击杀也不表示每张后续刀都免代价。

青龙的追杀是另一张杀，通常插入在外层被闪的杀尚未结束时。决定是否追杀，应比较停手与追杀的全部后续结果，先结算内层，再返回外层，按每张杀分别判断G4/G5。不把“这一串动作死人了”当作每张刀都有击杀。[历史青龙与使用流程依据](https://gltjk.com/sanguosha/rules/card/equipment.html)

单目标外层被闪、内层3势4伤确实击杀但未终局：内层保势免付，外层仍无伤未击杀，须清当前势或失去1体力。若内层没杀死而清势，返回外层可清0摸0，不必再次自残；若内层选择失血保势，则外层也有失血或清势选择，不能忽略连续两次失血风险。外层若有多个直接目标，恢复时还须继续剩余目标，不一律当它已永远无伤。

嵌套内层造成正数伤害会影响整个自己回合的G1，外层被闪不能把这份伤害抹掉。已经终局则不再为了摸牌、保势或后续传导继续预算。未知的特殊额外杀归因须补查，不从普通“技能触发于杀”推出它的死亡属于原杀。

## 7. 锁心：保留哪些杀、重铸多少、链谁

在出牌阶段结束时，先决定重铸的牌集合，再摸牌，再按新局面决定目标集合。已经结束出牌阶段，不能指望重铸摸来的桃、装备、拆牌照常马上主动使用；它们主要服务于之后的响应和下轮。

保留杀的需求包括：接下来南蛮/决斗的响应、下个可靠出刀窗口、与装备技能配合、颜色属性点数的特殊用途。预计结束阶段能获得弃牌堆杀会降低攻击种子的保留需求，但要考虑牌被移走、阶段中断和捡到的杀是否适配。不能把某张重铸杀必然返还作为默认。

通常先重铸不能形成有效后续用途的多余杀。每多重铸一张，分别比较换来的手牌质量、额外一个有价值铁索目标、失去该杀的用途和弃牌压力。可以只重铸一张、全部重铸或不发动，不按“有几张杀就铸几张”固定处理。

铁索目标按以下顺序评估：解除自己或关键队友正在承担的连环危险；为接下来可靠的己方属性伤害增加敌方受害人数；拆掉敌方可利用的混合连环。没有正收益的目标就选 0 人。已横置的敌人再选会解链，不是再加一层；选择自己也可能是解链，不一概禁止。

这是默认比较方向，不是无条件“先给队友解链”：队友连环没有现实威胁，而敌方新增横置能立即形成可靠赢局机会时，应保留更高优先级的方案。敌方已横置者若能被对手利用，给它解链也可能是防守行为。

先看下一次属性伤害是谁、何时能造成，再布链。自己的锁心通常不能增强本阶段已经结算的那一刀；2 势且本回合无杀伤，结束阶段才到 3 势，锁心是在准备未来火伤。敌方会在自己下次行动前出属性伤害，布链可能变成送给对手的武器。

至少检查全场链条和行动顺序，不能为了名额多就多链。可只给队友解链，不加敌人；可只换牌不链；可为救关键角色重铸唯一一杀。虚拟铁索可能被无懈或触发相关技能，效果落空不撤销重铸收益。

经典普通无懈按铁索对当前目标的效果处理，不是一张无懈默认抹掉全部目标。为己方解链可能被单独抵消，而给其他人横置仍成功，形成不安全的剩余链；后续出刀按实际效果重算。此处不套用国无懈。[历史依据与推导](https://gltjk.com/sanguosha/rules/card/scroll.html)

## 8. 普通行动与身份

弃牌时优先留下实际防御与救援，再保留有明确窗口的攻击材料；势越高且火伤风险越大，越不能机械留杀舍闪。蓄势预计补杀时，可优先弃置冗余杀，但不依赖指定找回其颜色或属性。

受到杀或锦囊时按生存和阵营收益响应。打出杀响应南蛮、决斗通常不支付拔刀代价；不要为了“藏刀”拒交杀吃伤害。借刀或其他回合外使用杀则单独比较伤害、连环和二选一，不照搬打出杀。当前自己回合中由技能使用的杀造成伤害也可能改变 G1，不只统计普通出牌按钮。

主公优先降低自身死亡和误杀忠臣的风险；忠臣可为保主接受自损资源；反贼优先制造可靠杀主窗口，队友牺牲须与终局收益比较；内奸以自己成为最后存活者为目标，避免火链提前杀主。身份未知时用行为证据更新判断，不直接知道暗身份。

身份与图上的“中”势力分开。主忠要清除敌方但不得误认同势力就是队友；反贼在杀主还不可靠时也可以优先消灭关键保护者；内奸不以永久中立或机械帮助弱方代替赢局，应保住主公、减少其他角色，并为最终单挑保留资源。公开队伍模式按公开队伍关系替换身份判断，胜负与奖励必须另取该模式规则。

## 9. 桌面验收场景

| 场景 | 应有选择或判断 |
| --- | --- |
| 2 势，敌人 2 体力、无牌无防御，所有有资格救援者也无手牌/求救技能，击杀有阵营正收益 | 可以现在用 3 伤杀，无需等到 3 势 |
| 4 势黑杀对仁王盾，急迫局面不存在 | 不将大伤数字当有效输出；先比较拆盾、红杀和等待 |
| 3 势，两名敌人和己方 1 体力主公横置 | 出刀先看整条链；不因能杀敌并保势就忽略主公 |
| 3 势，目标被打到 0，但公开桃救回 | 没死，仍二选一；此回合已造成伤害不能蓄势 |
| 3 势，杀被闪，本人 2 体力且无防御 | 清势是合理默认；只有本回合整体无杀伤且到达蓄势窗口，才重新得势与补杀 |
| 0 势，杀未造成死亡 | 选清 0 摸 0，不平白流失体力 |
| 一张杀致命直接目标，同时链伤己方 | 不用“只要有人死就免费”判定好坏，计阵营与奖惩 |
| 杀造成伤害，出牌结束仍有多余杀 | 仍可锁心；不是旧版用杀后禁用 |
| 仅一张杀，自己连环且下一家敌人有公开火伤 | 可重铸唯一杀给自己解链；不机械保一杀 |
| 重铸杀摸到桃，出牌阶段已结束 | 不制定随后主动吃桃的普通出牌计划 |
| 已横置敌人是己方未来属性伤害受害者 | 不为了用满目标名额把它解链 |
| 被乐跳过出牌阶段 | 不自动安排锁心；是否到达蓄势窗口单独判断 |
| 南蛮要求交杀 | 打出杀，不按使用杀扣拔刀代价 |
| 此刀经传导杀死主公但其他人仍活着，自己是内奸 | 避免该路线；不能假定后续传导能补成自己单独存活 |
| 寒冰对满血狮子＋连弩敌人，扣血仅1伤，敌人有可追踪连杀威胁 | 比较防伤拆牌；无人死仍付款，本回合完全无杀伤才可蓄势；不声称必然保主 |
| 寒冰可拆牌，但此刻直接伤害能可靠结束敌方核心威胁 | 不能为多一势机械放弃伤害或击杀 |
| 青龙外层单目标杀被闪，内层杀确实击杀且未终局 | 内层免付，外层仍二选一；追杀不等于全段免费 |
| 青龙内层未击杀而清势，返回被闪的单目标外层 | 外层清0摸0；无需固定再失血，本回合若内层有伤则不蓄势 |
| 连弩第一刀未杀死而清势，第二刀原本靠势够到远敌 | 重新查范围，不能沿用第一刀可选目标；重新查增伤与属性 |
| 连弩2势，前刀造成3伤未击杀并失血保势，后刀被闪而清势，之后停手 | 结束仍为0势，不蓄势补杀；后刀若失血保势则留2势，不自动到3势 |
| 方天最后手牌为2势火杀，横置A3/B5，无响应救援，A死不终局 | 比较多目标：B可先链3后直接3；按动态状态，勿只算各吃一份链伤 |
| 多目标火杀首个伤害造成即时终局 | 后续目标、链伤和奖励不当成可兑现收益 |
| 锁心解己方链被普通无懈，横置敌方成功 | 识别残余混合链，不能当全部铁索成功或全部失败 |
| 高势伤害已远超敌人体力，防御障碍仍是公开闪/减伤 | 等待须有新理由；比较拆防、控牌、兑现，不无限囤势 |
| 1体力、高势、缺防御，只有被公开防具挡住的杀，没有更好的过牌/击杀方案 | 零伤清势换牌可作生存计划；摸不到防御与弃牌损耗也须评估 |
