# Briefs

Store task briefs for CC_Crew workers here.

Briefs should be project-specific but role-clean. They should reference the
generic role protocols in `AGENTS/`, then provide exact project paths, accepted
facts, scope, and acceptance criteria.

Recommended naming:

- `YYYYMMDD-topic-explorer.md`
- `YYYYMMDD-topic-coder.md`
- `YYYYMMDD-topic-reviewer.md`
