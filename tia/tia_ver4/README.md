# 黑纱鸣礼·缇娅 tia_ver4

无名杀联机可用角色扩展包。

## 安装

将本目录作为完整扩展目录放入：

```text
game/noname/resources/app/extension/tia_ver4
```

扩展入口为 `extension.js`，角色包入口为 `character/index.js`，两处均已设置 `connect: true`。

## 角色

- 武将：缇娅
- 称号：黑纱鸣礼
- 势力：西（使用无名杀内置 `western`）
- 体力：3
- 技能：枪礼、荣光、悼舞

## 实现要点

- 弹药使用 `player.storage.tia4_ammo` 元数据数组同步，FIFO 队列。
- mark 显示格式为：

```text
当前弹药数：4
1：[未知]
2：[8]
3：[未知]
4：[未知]
```

- 暗置弹药 UI 永远显示未知；代码内部保留点数用于荣光判定。
- 实体手牌【杀】/【酒】由枪礼强制视为自用牌【弹仪】；【弹仪】不是锦囊牌，不能被【无懈可击】响应。其效果为选择“暗装2次”或“摸2张牌并弃置此次摸到的一张牌”。弹药超过上限时按 FIFO 排出最早弹药。
- 悼舞在缇娅回合外失去手牌时自动暗装，且回合外黑色手牌可视为【杀】或【闪】。
- 悼舞转化牌进入弃牌堆时可明装，明装弹药 `visible: true`；荣光初始击发消耗明装弹药时，该【杀】为火【杀】。
- 荣光额外结算通过 `useCardToEnd` 增加同一张【杀】的 `effectCount`，不会额外计入使用【杀】次数。
- ver4 修复：荣光额外结算前会继承青釭剑的 `qinggang2` 破防标记，避免第二次结算被藤甲按普通【杀】取消。

## Smoke 建议

1. 持有枪礼时：实体手牌【杀】/【酒】在牌名层强制视为【弹仪】，目标为自己，不走【杀】的距离、次数和目标流程，也不能被【无懈可击】响应。
2. 使用【弹仪】：无论当前弹药数都可暗装2次；已有5/6发时分别 FIFO 排出最早的1/2发。
3. 缇娅回合外失去手牌：悼舞自动暗装一发暗置弹药；自己回合内失去手牌不触发。
4. 回合外悼舞可用黑色手牌当合法的【杀】或【闪】；自己回合内和装备区黑色牌不可用。
5. 悼舞转化牌进弃牌堆时：可改为一发明置弹药；该弹药由荣光击发时杀改为火杀。
6. 荣光主动当【杀】使用：占一次出杀次数；后续额外结算不再占次数。
7. 荣光第 1/2/3/4 次结算阈值分别为 12/8/4/0，超过则本次结算 `unhurt`。
