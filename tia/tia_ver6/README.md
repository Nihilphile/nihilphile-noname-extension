# 黑纱鸣礼·缇娅 tia_ver5

无名杀联机可用角色扩展包。

## 安装

将本目录作为完整扩展目录放入：

```text
game/noname/resources/app/extension/tia_ver5
```

扩展入口为 `extension.js`，角色包入口为 `character/index.js`，两处均已设置 `connect: true`。

## 角色

- 武将：缇娅
- 称号：黑纱鸣礼
- 势力：西（使用无名杀内置 `western`）
- 体力：3
- 技能：枪礼、荣光、悼舞

## 实现要点

- 弹药使用 `player.storage.tia5_ammo` 元数据数组同步，FIFO 队列。
- mark 显示格式为：

```text
当前弹药数：4
1：[未知]
2：[8]
3：[未知]
4：[未知]
```

- 暗置弹药 UI 永远显示未知；代码内部保留点数用于荣光判定。
- 实体手牌【杀】/【酒】由枪礼强制视为自用牌【弹仪】；【弹仪】不是锦囊牌，不能被【无懈可击】响应。效果为选择"暗装2次"或"摸2张牌并弃置一张牌（手牌或装备区）"。弹药超过上限时按 FIFO 排出最早弹药。
- 悼舞有两个独立效果：(1)被伤害牌指定时，黑色手牌可视为合法【杀】或【闪】响应；(2)使用实体【杀】或【闪】响应伤害牌后，可在结算后将该牌截胡明置为弹药（不再进弃牌堆），该弹药 `visible: true`，荣光初始击发时此【杀】为火【杀】。
- 荣光额外结算通过 `useCardToEnd` 增加同一张【杀】的 `effectCount`，不会额外计入使用【杀】次数。
- ver5 继承 ver4 的 青釭剑 `qinggang2` 破防标记修复。

## ver4 → ver5 变更

1. **弹仪摸牌弃牌**：弃牌范围从"此次摸到的牌"改为"任意手牌或装备区牌"（"he"）。
2. **悼舞触发条件**：恢复 getDaowuContext 伤害牌判断，移除回合外无限制响应。
3. **悼舞明装时机**：从"跟踪 cardid → 等进弃牌堆 → 弹窗回收"改为 `respondAfter` 直接截胡。
4. **移除 daowu_darkload**：回合外失去手牌暗装机制已删除。
5. **悼舞牌范围**：仅限手牌黑色牌（"h"），不再包含装备区。

## Smoke 建议

1. 持有枪礼时：实体手牌【杀】/【酒】在牌名层强制视为【弹仪】，目标为自己，不能被【无懈可击】响应。
2. 使用【弹仪】：选择"暗装2次"或"摸2张并弃置一张牌"。弹药超过上限时 FIFO 排出。
3. 悼舞仅在被伤害牌指定为目标时可触发：黑色手牌当【杀】或【闪】响应（匹配当前事件要求）。
4. 悼舞响应后：可直接将实体牌明置为弹药（截胡），不再进弃牌堆；荣光击发时改为火杀。
5. 荣光主动当【杀】使用：占一次出杀次数；后续额外结算不再占次数。
6. 荣光第 1/2/3/4 次结算阈值分别为 12/8/4/0，超过则本次结算 `unhurt`。
