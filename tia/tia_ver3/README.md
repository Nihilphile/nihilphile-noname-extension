# 黑纱鸣礼·缇娅 tia_ver3

无名杀联机可用角色扩展包。

## 安装

将本目录作为完整扩展目录放入：

```text
game/noname/resources/app/extension/tia_ver3
```

扩展入口为 `extension.js`，角色包入口为 `character/index.js`，两处均已设置 `connect: true`。

## 角色

- 武将：缇娅
- 称号：黑纱鸣礼
- 势力：西（使用无名杀内置 `western`）
- 体力：3
- 技能：枪礼、荣光、悼舞

## 实现要点

- 弹药使用 `player.storage.tia3_ammo` 元数据数组同步，FIFO 队列。
- mark 显示格式为：

```text
当前弹药数：4
1：[未知]
2：[8]
3：[未知]
4：[未知]
```

- 暗置弹药 UI 永远显示未知；代码内部保留点数用于荣光判定。
- 出牌阶段的实体【杀】/【酒】仍按原牌名使用，但被改为无目标摸牌，不受距离和次数限制。
- 悼舞弹药 `visible: true`，荣光初始击发消耗悼舞弹药时，该【杀】为火【杀】。
- 荣光额外结算通过 `useCardToEnd` 增加同一张【杀】的 `effectCount`，不会额外计入使用【杀】次数。
- ver3 修复：荣光额外结算前会继承青釭剑的 `qinggang2` 破防标记，避免第二次结算被藤甲按普通【杀】取消。

## Smoke 建议

1. 出牌阶段使用手牌实体【杀】/【酒】：仍算使用【杀】/【酒】，不选目标，摸一张牌，不计次数，不受距离卡住。
2. 使用/打出【杀】或【闪】后：枪礼补一发暗置弹药，上限 6。
3. 被伤害牌要求响应时：悼舞可用黑色牌当合法的【杀】或【闪】响应，黑色【杀】也可以经悼舞当【杀】响应。
4. 悼舞响应牌进弃牌堆时：可改为一发明置弹药，并额外触发枪礼暗置弹药。
5. 荣光主动当【杀】使用：占一次出杀次数；后续额外结算不再占次数。
6. 荣光第 1/2/3/4 次结算阈值分别为 12/8/4/0，超过则本次结算 `unhurt`。
