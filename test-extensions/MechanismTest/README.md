# MechanismTest 0.2

独立的无名杀 1.11.3 联机场景准备扩展。

- 扩展：`MechanismTest`
- 角色包：`mechanism_test`
- 武将：`mechanism_test_actor`
- 主技能：`mechanism_test_console`
- 版本：`0.2.0`

本扩展不属于 Nihilphile 武将包。0.2 提供：

- 无实体材料普通/火/雷【杀】，忽略距离和次数且不增加普通杀次数，仍遵守目标禁止并走原生响应/伤害链；
- 1/2/3 快捷值与逐位十进制自定义正整数，供伤害、回复、失去体力和护盾增减共用；
- 当前引擎全部已注册卡牌的按类别、中文名与精确 ID 导航生成，可选花色、点数和【杀】属性；
- 使用原生合法性检查移动装备区/判定区牌；
- 按“选择顺序即从顶向下”的约定生成并控制牌堆顶实体牌；
- 旧版获得、弃置、交给与快捷预设。

数值只受 JavaScript 安全整数这一技术边界；不提供任意字符串牌注册，也不直接修改普通杀计数或被测技能存储。自动化结果与真实联机验收分别记录在 `doc/taskboard/mechanism-test-v02/`。
