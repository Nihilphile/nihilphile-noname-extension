# 无忧 AI 三层决策设计 v3

2026-10-12。三层方案已实现，含独立审查和实机复盘后的修正；后续牌型补充与实际候选状态见[实现记录](无忧_AI_v3实现记录.md)及[验收记录](无忧_AI_v3验收记录.md)。武将机制和正式禁选保持，工作分支 `codex/wuyou-ai-v1`。

本稿覆盖忆支付、全场收益、出牌入口三层。友伤取舍以用户例子为准：可靠直接胜局可以接受牺牲队友；普通一敌换一友通常拒绝；击杀敌人伴随非致命友伤可以考虑；同一结算分支里两敌换一友可以考虑。队友死亡是代价，不是正收益。参数是可调整的策略初值，不是实测胜率。

后续按牌型细化见[牌型收益补充](无忧_AI牌型收益补充_v3.md)：闪/无懈只对 AI 跳过追还规划；过拆、顺手、治疗摸牌及群体牌的四级增量按实际敌友、区域库存和结算次数计算，没有固定的“某一级一定更值”。

## 1. 新旧合同与机制事实

替代 v1 的“主动友伤直接排除”“原牌非正不进入”“出牌不计追还”“友方取牌/直击/增次一律关闭”，以及 v2 的末忆成本 0.15/0.30。旧稿和既有测试保留为历史；实现 v3 时须更新相应断言，不能并存互相矛盾的规则。

- 同花色只比较当前真正能执行的最佳牌及目标方案。用牌后其他同色手牌强制重铸，不再累加它们的未来使用收益；重铸成本每张实际用牌只记一次。
- 追还在 `useCard2` 支付，每色至多一忆。本牌结束后重铸产出的忆不能预支。
- 支付 k 色翻开 k 张牌后弃置，翻牌不是获得手牌。m 是支付花色与翻开花色的交集大小。
- m≥1 可加一合法目标，m≥2 可统一开启每目标每次效果后的随机取牌，m≥3 可统一不可响应，m≥4 可再结算一次。四项可取消，不能只偷敌人或只让敌人不可响应。
- 目标死亡、排除、整次效果取消或无手牌时不凭空取牌。自取自己记零净收益。杀被闪避不等于整次效果取消，按真实 `useCardToEnd` 是否发生判断。
- 桃园满血目标由 `ignoreTarget` 跳过，也不能从其取牌。受伤目标先回血再取牌；第二轮重新检查是否仍受伤、仍有手牌。
- 不可响应不等于无视免疫、减伤、护甲、恍惚或濒死救援。HP 到零不等于确认死亡。
- 死亡逐个结算，模式可能立即终局；其后尚未发生的击杀、回血和取牌不得入账。

## 2. 一个规划器，三个调用时点

纯规划器只读快照，真实技能事件负责支付与状态变更。

```text
PLAN_USE 出牌阶段
  枚举原生合法牌/目标方案（含完整强制目标）
  → 原牌 + 追还策略 + 一次重铸，全场估值并检查风险
  → 选择正净收益最优行动；否则原生合法回退/停手
  ↓ 真实使用牌
PLAN_PAYMENT / useCard2
  重读实际目标、忆与公开状态
  → NO_PAY 与至多 15 个支付集合比较
  → 正增益且通过门控才支付
  ↓ 真实翻牌 m
PLAN_SUFFIX 四个选项窗口
  固定已经接受/取消的选项，枚举剩余合法组合
  → 返回当前窗口的选择，下一窗口按实际状态重算
  ↓ 用牌、强制重铸结束
作废旧快照，回到 PLAN_USE
```

调用示意（待实现）：

```js
planWuyou({stage:'use', snapshot, nativeCandidates});
planWuyou({stage:'payment', snapshot, actualUse});
planWuyou({stage:'suffix', snapshot, actualUse, matched, fixed});
// 返回 action / target / spendSuits / option / reason / diagnostics
```

内部职责：公开快照 → 原生效果队列 → 有限结果树 → 终局/友伤门与评分 → 支付/后续策略枚举。终局预测是纯函数，严禁调用会改身份、展示身份或结束游戏的 `game.checkResult()`/`game.over()`。

快照至少含本人身份/队伍、己方手牌、四色忆；各人的公开 HP/上限/护甲/手牌数/装备/技能/标记/阵营证据；合法目标、排除、效果次数、既有不可响应状态、顺序规则、固定选项。不得读敌方牌面、牌堆或隐藏身份。身份不明者不能为“杀两敌”充数，也不能视为已证明安全的牺牲对象。

结果树的每条路径保存：概率或概率区间、存活/死亡掩码、各人 HP/手牌数、响应库存、效果队列前缀、终局 WIN/LOSS/NONE/UNKNOWN、体力与死亡收益 H、牌收益 C、未知原因。不得只返回裸分数。

## 3. 全场收益层

### 3.1 成对的有限轨迹

对相同潜在响应/救援条件分别计算原牌不升级和强化轨迹，取差值。原牌已有的伤害、回血、摸牌不重复算作追还增益；两边不能各自独立抽样后把随机差异当作强化效果。

按原生队列推进：合法性/排除/忽略 → 响应或抵消 → 实际伤害/回复/牌流 → 濒死救援 → 确认死亡及模式判定 → 仍继续时的效果末取牌 → 本次 `useCardAfter` 强制重铸。群体效果若是单事件，保留该事件边界。额外一轮继承第一轮后的 HP、手牌、存活、消耗状态，不重置。

不能直接把 `use.targets` 当前数组当作最终顺序：原生还会排序；对抗模式的南蛮、万箭可能有顺/逆序选择。未选择且本版未接管方向窗口时，对所有合法方向分别预测，风险取最坏界、收益取最低值；选定后使用真实方向。不假称自己一定能选到有利方向。

### 3.2 信息与适配范围

首批适配普通杀、桃、无中、桃园、南蛮、万箭；按后续牌型合同补充顺手、过河的公开区域库存和追还收益。决斗仍待响应适配；闪、无懈由 AI 直接跳过主动追还规划。复杂扩展牌沿用原生出牌，无法建模的升级收益记零；原生 `get.effect>0` 不等于全场安全。

无中摸牌数也由模式决定：原生对抗模式在目标所属方人数少于对方时为三张，否则两张，须逐目标读取公开存活人数计算。本稿普通友方两摸见证限定不触发三摸；标准 2v2 的己方仅剩一人时没有可追加的存活队友，不能凭空造“1v2 给友方三牌”的案例。

普通未知手牌的响应排序先验：需单张杀/闪时，按公开手牌数 h 使用 `Binomial(h,0.25)` 生成可响应张数 0/1/≥2，截断于本次最大需求；己方用实际己方手牌，公开无牌且无替代响应能力则为零。重复结算共享响应库存，不能每轮按原手牌数重新掷骰。此先验仅用于普通收益，不宣称准确胜率。

在这种潜在库存分支里，随机取走一牌时按“剩余响应牌数/剩余手牌数”分支扣响应库存；新得未知手牌按同一先验加入。多张响应要求、公开替代响应、花色减伤必须由相应适配器改写，不能硬套单张 0.25。未知花色只用等可能先验估计其是否进入本次重铸组，不读取实际牌面。

救援、免伤、死亡技、治疗后摸牌、杀人奖惩等若影响关键结果而未适配，保留上下界和 UNKNOWN。未知救援不能写成“无桃所以死亡”；普通排序可参考原生效果，可靠胜局及两敌换一友证明只使用公开可确定部分。未知不等于整张牌必拒绝：无需死亡证明的普通非致命增益仍可成立。

终局首批适配常规身份及无替补标准 2v2：

- 2v2 从当前行动者一方判断，敌方无人存活则赢、己方无人则输，每次真实死亡后检查。替补/特殊规则/未适配模式为 UNKNOWN。
- 常规身份用本人身份、公开主公及引擎胜负条件。本人反贼且仍存活时，主公确认死亡可证明本方胜；主公/忠臣方主公死亡为败。其余结论须有足够公开身份信息，不能遍历隐藏身份表。内奸或特殊身份只有规则适配完整且证据充分才证明。
- 原生部分死亡后事件晚于模式胜负检查；终局立即停止。杀反贼奖励、主公杀忠臣弃牌等若改变后续效果，须适配执行或转 UNKNOWN，不能忽略后仍证明杀局。

### 3.3 效用初值

| 变化 | 分值 |
| --- | ---: |
| 普通敌人实际 HP 或护甲损失 | +2 / 点 |
| 友方（含本人）实际 HP 或护甲损失 | −3.5 / 点 |
| 敌人确认死亡，另加 | +4.5 / 人 |
| 友方确认死亡，另加 | −6 / 人 |
| 友方回复 / 敌方回复 | +2 / −2 每点 |
| 行动者或其他友方获得牌 | +0.8 / 张 |
| 敌方获得 / 敌方失去牌 | −0.8 / +0.8 每张 |
| 其他友方失去牌 | −2.2 / 张 |
| 公开确认的己方胜 / 败 | 终点总值 +100 / −100 |

同一张牌每端只记一次。取敌牌净 +1.6，取友牌净 −1.4，自取零；无中给合法队友两牌 +1.6，不能只计自己。本人响应或失牌按己方持有价值扣除，默认 −0.8/张，已知救命牌由公开/己方事实加价。死亡不扣负 HP：1 HP 吃 2 伤计 1 HP 和一次死亡；获救则用最终 HP 和实际救援牌流，不计死亡。

实战补充：公开护甲也是耐久资源，实际吸收的伤害按上表计损失，不能为了重铸把队友护甲当免费消耗。HP 与护甲分开记账；只有穿过护甲的伤害改变 HP 并参与死亡判断，不重复计同一点伤害。沿用已有耐久权重，尚未另外模拟兵狼卫护甲对未来摸牌及手牌上限的技能收益。

终局分覆盖该路径普通局面分，不计算“赢后再摸牌”。关键队友只由明确公开胜负规则识别：主公/最后存活队友优先用终局门；其他已适配公开必保角色将额外死亡罚分从 −6 提至 −10.5，不凭武将名任意贴标签。

### 3.4 友伤与牺牲门

门控输入必须为联合路径。出牌相对停手检查整张牌；支付相对原牌不付检查新增风险。翻牌后首窗保存不可变的 `decisionRoot`（支付已发生、尚未加任何升级的实际状态），四窗都将完整候选与此 root 比较；已固定 prefix 仅限制可行域。不能逐窗把先前追加的敌死移入基线，导致后窗再也凑不到整体交换收益。“保留 prefix、剩余全取消”仅作当前兜底/续作比较，不替换交换基线。已不可撤销的原牌友伤不能在追还窗口假装取消。

“新增”必须逐配对路径定义：新增败局概率为 `P(candidate=LOSS 且 root≠LOSS)`，UNKNOWN 按上界处理；不能用两个边际败率相减。新增友死/敌死为候选死亡集合减去同一潜在世界的 root 死亡集合；新增友伤分别记录对应角色实际 HP 损失差及护甲损失差的正部。反例：root 在世界 A 败、候选在世界 B 败，A/B 各 50%；边际败率差为零，但新增败局是 50%，必须被门识别。

1. **可靠直接胜局**：WIN 概率下界 ≥0.90、LOSS 上界 ≤0.02，且没有未纳入界的规则未知，可以越过通常友伤/友死交换门。必须计算完整政策，含翻牌失败；不能用“m=4 时必胜”冒充支付前 90% 胜。未知手牌先验不能独自提供胜局证明。
2. **败局风险**：相较基线新增 LOSS 概率上界 >0.02，且不满足上一条，拒绝该候选。不存在安全基线时，选择 LOSS 上界最低，再比较 WIN 下界/净值的合法后续，避免等待不存在的安全分支。
3. **新增友伤**：除已证明 WIN 路径外，若新增友方 HP/护甲损失或死亡，要求包含护甲耐久的体力与死亡期望增量 H 严格 >0。几张牌的收益不能把负的友伤交换洗正；友方失牌仍按牌代价处理。
4. **新增友死**：非胜局路径的新增友死概率上界 >0.05 时，要求这些路径中至少 80% 的概率质量，在同一路径、终局前证明新增敌死人数 ≥2×新增友死人数。下界不足拒绝，未知尾部计入不合格质量。一友两敌可进入下一步，两友两敌不通过。
5. **普通净值**：从 H+C 额外扣 `0.25×CVaR10(新增友方体力/护甲/死亡损失)`，再计资源/重铸净成本，严格 >0 才选。CVaR10 是最坏 10% 路径的平均损失，WIN 路径记零，不足 10% 用零补齐；这是策略参数，不是胜率校准。

支付/选项比较时，不能把原牌已能击杀的敌人重复当作新增友死的补偿；出牌时才计算整张牌的击杀。不能用不同随机结果的平均击杀数拼接 2:1。

可达见证（敌我关系及无救援/免伤须公开可证明，无额外触发技/次序败局干扰，均为新增结果）：普通交换行另假设还有其他敌人存活，未触发模式终局；例如标准 2v2 已杀光两敌时应直接用 WIN，不套普通 2:1 分数。

| 同一路径的结果 | H 与尾部代价 | 决定 |
| --- | --- | --- |
| 一名 1 HP 敌死、一名 1 HP 友死 | 6.5−9.5<0 | 普通 1:1 拒绝 |
| 两名 1 HP 敌死、一名 1 HP 友死 | 13−9.5−2.375=1.125 | 可进入成本比较 |
| 一名 1 HP 敌死、友掉 1 HP 仍存活 | 6.5−3.5−0.875=2.125 | 可进入比较 |
| 两敌各掉 1 HP、一友掉 1 HP | 4−3.5−0.875<0 | 本组初值仍拒绝 |
| 50% 两敌死友活；50% 仅友死 | 友死路径合格比例 0% | 拒绝伪平均 2:1 |
| 反贼可靠杀主公，即使途经友死 | 可靠胜局门 | 可考虑，先发生己方败局则拒绝 |

## 4. 资源层：末忆有价格，组合不封死

库存势能用于未建模的后续选择价值，不代替当前事件中的真实防御：

```text
v(0)=0, v(1)=0.55, v(2)=1.65, v(3)=1.90
v(n>=4)=1.90+0.20*(n-3)
D(有效花色数 0,1,2,3,4)=[0,0,0.15,0.35,0.60]
V(M)=sum_s v(M[s])+D(有效花色数)
无中途忆变化且无本牌后重铸时：Cost(M,S)=V(M)-V(M-S)
一般情况：CostFuture(S)=E[V(M_end,NO_PAY)-V(M_end,S)]
```

无后续产忆/耗忆时，末忆基础成本 0.55，可能另失去花色组合价值；2→1 成本 1.10，体现失去恍惚门槛；3→2 仅 0.25，≥4 边际 0.20，更愿意花余量。每次真实消耗后重算，不锁回合初库存。

一般情况必须在支付/不付的成对轨迹都完成本次重铸后，用各自的 `M_end` 算势能差。若两边必定同色重铸 G 忆，成本为 `V(M+G)-V(M-S+G)`：M=1、G=1 时是 1.10 而非 0.55；M=2、G=1 时仅 0.25 而非 1.10。取牌会改变 G 时，按联合路径分别算，不先把平均库存塞入非线性 V。本牌中已实际发生的恍惚防御/耗忆在轨迹结算，末端势能只给剩余库存定价，不再为同一次防御另外收费。

沿用公开危险判断（低血且缺可用常规应对等），危险时关闭让任一色 2→1 的支付集合。仅完整支付策略通过可靠胜局门时允许例外，罕见 m 单分支能赢不够。n=1 不具备当前恍惚减伤能力，不冒充保命库存。

概率沿用等可能独立花色近似，不读牌堆：

| k | P(m=0) | P(m=1) | P(m=2) | P(m=3) | P(m=4) |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1 | .75 | .25 | 0 | 0 | 0 |
| 2 | .25 | .625 | .125 | 0 | 0 |
| 3 | .015625 | .328125 | .5625 | .09375 | 0 |
| 4 | 0 | .015625 | .328125 | .5625 | .09375 |

四种支付，至少两匹配 98.4375%，至少三匹配 65.625%，四匹配 9.375%。额外结算的 AOE 两点只能按真实四匹配分支估值，不能当作必然。

首版采用后向归纳的**可执行条件政策**，不声称跨 m 的全局最优。对每个 S、m 建立支付后的 `decisionRoot`，用与真实 suffix 相同的条件风险门、效用排序和固定 tie-break 枚举合法组合，保留全取消，得到确定的 `SuffixPolicy(S,m,root)`。支付只估算这组真实窗口会执行的政策，再对混合结果加做完整支付门：

```text
U(非终局轨迹)=H+C_before_recast+C_recast+V(M_end)
U(终局轨迹)=WIN:+100 或 LOSS:-100，不再附加牌/忆剩值
rawDelta(S)=sum_m P(m|size(S))*E[U(SuffixPolicy(S,m,root))-U(NO_PAY)]
score(S)=rawDelta(S)-新增友伤尾部罚分
best=max(NO_PAY=0, 所有合法且通过政策门的 S)
```

U 是未扣尾部罚分的完整效用；C_before_recast 只含重铸前牌流，C_recast 只含重铸牌流，不能同一牌流记两次。U 已通过两端库存含有 CostFuture，不再额外减一次 Cost。H 门独立读取 H。条件政策排序可使用该阶段尾部罚分，但传给支付层的是原始路径分布与未罚 U，混合后只扣一次支付层尾部罚分。每个 m 可取消危险升级，但已付忆造成的即时防御损失仍留在路径内。确定终局后库存没有机会成本。

预演和真实选项窗口必须使用同一个条件规划函数、同一 root 与候选排序；固定 prefix 只收窄可行域，无新信息时应返回原先完整政策的相同后续。实际公开信息变化则重算并记录 `MODEL_CHANGED`。这样不会支付时算进一个翻牌后被自身条件门拒绝的动作。代价是可能错过跨 m 混合后合算、但某个已观测 m 下不划算的政策；首版有意不让其他未发生的匹配结果授权当前坏交换。CVaR 和 80% 门不具可加性，不能据此宣称枚举 15 个支付集合就找到所有政策的全局最优。

本牌受支付后恍惚/其他已适配库存能力影响时，必须用 M−S；结束重铸不能提前弥补中途防御。仅支付后防御影响相同的集合能共用物理轨迹，各自末端库存仍需单独赋值，不能仅按 k 共缓存效用。翻牌后已付忆沉没，suffix root 也用已扣的忆，后续只计选项造成的库存差，不再次扣支付成本。平分先选较低新增败局、较低新增友死、较低成本、较少花色，再稳定座次/花色顺序。

### 4.1 数值见证

- 仅一忆，且本次轨迹无其他产忆/耗忆/重铸差异，桃追加普通队友回 1 HP：`0.25×2−0.55=−0.05`，不赌；无中给友两牌：`0.25×1.6−0.55=−0.15`，也攒。救命/终局额外价值须有状态事实，不能给普通桃任意提分。
- 同色三忆，同样无后续忆变化的桃：`0.25×2−0.25=+0.25`，可付，证明余量分支可达。
- 四色各一忆，原手牌只有此桃园；自己和三友、三敌均缺至少 2 HP，其他友方空手，三敌至少两手牌，无相关触发技。桃园首轮回血净值 `4×2−3×2=2`；m≥2 取三敌牌 +4.8；m=4 再回血净 +2、再取牌 +4.8。增量期望 `.984375×4.8+.09375×6.8=5.3625`；先保守忽略取牌后可能新增的忆，四色末忆成本上界 `4×.55+.60=2.8`，净值下界 `+2.5625`。本例全部未知牌统一值 0.8，同色取牌再重铸保持手牌张数且只增加末端忆，因此不会降低该下界。四种全付是正候选，仍须与其他 14 集合比较；若需评具体保命牌价值则重新计算，不能套下界。
- 敌改为满血则被跳过，不能继续套 +4.8；友改为有牌则减统一取友牌代价。这些变化必须可能反转支付决定。
- 万箭额外一轮若声称两敌换一友，须检查两敌确由升级新增死亡，第一轮未已终局。第一轮已杀敌、第二轮仅杀友不能沿用两敌收益。通过门的交换仅在实际允许该升级的 m 中计入。

## 5. 出牌入口层

每张合法牌/原生目标计划生成完整行动。群体牌评整套目标，不取单个敌人最大分；保留负贡献。不能因一个目标 `get.effect<=0` 删掉整牌，也不能跳过该负目标以虚增收益。

```text
Base(a)=原牌不追还、直至本次重铸结束，相对停手的效用差
UseScore(a)=Base(a)+最佳追还政策期望增量-完整行动的友伤尾部罚分
```

含追还失败的整个行动过终局/友伤门。两项都用第 4 节统一末端效用，追还增量传入未扣尾部罚分值；出牌层只对完整行动扣一次，不能再加一遍重铸或再减一遍忆成本。原牌非正但政策期望补回可以出；只有四匹配乐观结果补回、实际期望负则不出。原牌正而追还负，正常出牌并 NO_PAY。

同色先比较所有可执行候选总分，再留最佳。不能先按原生分只取前两张，否则追还才变正的桃园/万箭永远到不了。用含追还收益上界的上界剪枝；每张支持的全场牌、每个有合法追加友方的桃/无中先登记。

重铸只看本次将重铸的同色余牌，扣当前保留的防御/救援价值，加未知重铸牌统一期望及新忆势能，不虚构未知花色或连招。效果期间新得牌可能扩大重铸组，已知逐张算、未知用期望，不提前读牌。已消耗用牌材料不再次当重铸损失；原牌成本与重铸成本用同一行动基线，避免重复扣牌。

合法性先于收益：不能因可给队友桃而允许本人满血使用原生不允许的桃。原生距离、数量、目标限制保持，追还加目标按真实接口校验。

缓存绑定出牌事件及快照签名：手牌实体、忆、全场公开 HP/护甲/手数/状态/阵营证据、目标/排除、效果次数、方向、固定选项、`_aiexclude`。变化即失效；顺序/目标回调只查计划，不反复全树计算。原生效果采样加递归保护，不变更游戏状态。

### 5.1 原生入口接线合同

仅提高 `aiOrder` 不够。当前 `wyBuildSnapshot` 的 `positives` 预筛、群伤含友即置 false，以及 `player_use` 仅返回 `zeroplayertarget`，都会挡住原牌非正的组合。实现必须一起移除这些旧硬门，由完整行动计划决定 HOLD/USE 和目标组。

首选接线是仅在本人 `type=phase` 的 `onChooseToUse` 为当前事件安装命名的 `ai2` 目标评价适配器；`ai1/aiOrder` 负责按完整行动净值排序。原生 `ai.basic.chooseTarget` 对强制全目标组按目标评价的有符号平方根累加，故不能把总收益加到每个目标上。

- 单目标牌：完整计划选中的合法目标返回正评价，其余不选；目标评价只编码已审过的计划，不再另算一套追还收益。
- `selectTarget=-1` 全目标牌：完整原生强制组中固定一个 anchor 返回正评价，其余返回零。整个强制组仍由引擎选择，零不代表排除队友；总行动奖励只注入一次。
- 未适配牌、转换技能、非本人出牌阶段回调原 `ai2`；不影响真人点击、响应/救援事件或全局 `get.effect`。保存原回调于事件字段，不嵌套重复包装；序列化后的命名函数从事件读计划，不捕获本地闭包。计划失效时先刷新或使用原生回退，不用旧 anchor。
- 合法性仍由原生 `filterCard/filterTarget/targetEnabled/targetInRange/filterOk` 控制。不设置 `forced`、不改目标集合来跳过检查。

实现验收必须走真实 `chooseToUse → chooseCard(ai1) → chooseTarget(ai2)` 链：用原生目标分非正、完整计划正的桃园/万箭确认能被选；仅纯函数返回 USE 不算入口通过。若目标引擎版本改变此接线，先适配并证明同一合同，再启用 v3。

## 6. 有界实现与回退

每个 m 至多 `(1+合法额外目标数)×8` 个组合，不可用布尔项固定 false。先按组合/支付后防御掩码/方向缓存轨迹，再对 ≤15 个支付集合混合，不重复调用引擎 AI。

结果树状态为 `(共享潜变量, root 状态, candidate 状态, 两端死亡/终局前缀)`。只有两端所有后续相关字段都相同才合并，每层默认最多 64 对状态；不能分别压缩两棵树后拼接，否则会失去新增击杀/败局的相关性。保留终局和友死尾部；必须丢弃时整对丢弃，不重新归一化，概率单列 UNKNOWN，收益用上下界、风险取最坏界。每个真实规划窗口初始最多 32768 次“一个状态推进一个效果事件”，记录计数；超限保留已证实最优候选，未算候选只有上界不可能胜出才剪枝，否则退已验证安全动作，不输出未验证必胜。

风险跨阈值则拒绝该投机升级或采用保守后续；复杂牌/模式返回 UNSUPPORTED 并采用原生合法基线，但已知会输的风险不能靠回退绕过。useCard2 已出牌不能撤回，选择剩余合法动作中最少新增败局/友死风险者，必要时全取消。

诊断记录：阶段、牌/目标、S、m 分布、原牌值、增量、忆成本、H、友死合格比例、WIN 下界/LOSS 上界、尾部罚分、未知原因、预算、原因码。原因码至少 `SAVE_LAST_MEMORY`、`SURPLUS_POSITIVE`、`GLOBAL_GAIN_POSITIVE`、`ALLY_DEATH_BAD_TRADE`、`ALLY_DAMAGE_EXCHANGE`、`TERMINAL_WIN`、`EARLY_TERMINAL_LOSS`、`ORDER_UNCERTAIN`、`MODEL_UNKNOWN`、`BUDGET_FALLBACK`、`NO_POSITIVE_DELTA`。
