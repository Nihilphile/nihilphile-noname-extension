# 魔虚罗（八握剑异戒神将）— 行为设计文档

> Nihilphile 武将包 · 势力魔 · 男性 · 4体力  
> 诗句：布瑠部由良良 八握剑异戒神将魔虚罗

---

## 一、适应（锁定技）

> 当你成为其他角色的一张锦囊牌/【杀】的目标并结算后，若此牌没有被抵消，将其明置于你的武将牌上方作为【适】。与【适】同名的锦囊牌和与【适】同名且属性相同的【杀】对你无效。当【适】数量大于你当前体力时，全部弃置之且恢复一点体力。

### 1.1 哪些牌会被叠适

| 牌类型 | 子类型 | 触发时机 | 备注 |
|--------|--------|---------|------|
| 杀 | 普通杀 / 火杀 / 雷杀 | `useCardToEnd`（牌结算完毕 + 濒死结束后） | 存储在 mark 中的 key 为 `sha:fire` / `sha:thunder` / `sha:none` |
| 普通锦囊 | 过河拆桥、顺手牵羊、决斗、南蛮入侵、万箭齐发、无中生有、五谷丰登、桃园结义、火攻、借刀杀人、铁索连环 等 | `useCardToEnd` | 存在即叠，不限单体/AOE；被无懈抵消不叠 |
| 基本牌 | 桃、酒 | `useCardToEnd` | 自己对自己用也叠（版本 v2+ 改） |
| 延时锦囊 | 乐不思蜀、兵粮寸断、闪电 | `lebuEnd` / `bingliangEnd` / `shandianEnd`（`phaseJudge` 生效后，且需判定失败才生效） | 天过不叠 |

### 1.2 不叠适的牌

| 牌 | 原因 |
|----|------|
| 被无懈抵消的任何牌 | `_neutralized === true` 时跳过 |
| 装备牌（仁王盾、八卦阵等） | 不属于锦囊/杀/桃/酒 |
| 延时锦囊天过（判定成功） | `_result.bool !== false` 时跳过 |

### 1.3 同名免疫规则

| 牌类型 | 免疫条件 |
|--------|---------|
| 普通锦囊 | 同名即免疫（例如叠了过河拆桥后，任何人对你的过拆都无法选你为目标） |
| 杀 | 同名 **且属性相同** 才免疫（叠了普通杀后火杀仍可选中你；叠了火杀后普通杀不可选中你？属性=组件匹配） |
| 延时锦囊 | 同名即免疫 |
| 桃 / 酒 | 同名即免疫（适应后不能再对自己使用桃/酒） |
| 无懈可击 | **不在适应范围内**，无懈仍可被对已适应的锦囊打出（适应只不让选为目标，无懈不是锦囊） |

### 1.4 免疫实现

使用 `mod.targetEnabled` 在选取目标阶段拦截：

```js
targetEnabled(card, player, target) {
    if (isAdapted(target, card)) return false; // 牌无法选魔虚罗为目标
}
```

藤甲类比：不是结算阶段 cancel，而是**不能选为目标**。

### 1.5 叠适时机（关键！）

叠适发生在牌**完全结算完毕后**（`useCardToEnd`），而非伤害判定阶段。这意味着：

1. 杀先用 → 受伤 → 濒死救回 → **然后**叠适
2. 锦囊先结算 → **然后**叠适
3. 延时锦囊先判定 → 生效 → **然后**叠适

如此确保**濒死不会被叠适的回血干扰**——1 血 3 适被 1 点伤害打中：先进濒死（可被救），然后叠适，然后检测溢出。

### 1.6 溢出规则

- 任何时候叠适后立即检测：`countMark > hp`
- 若溢出：全部弃置 + 回复 1 体力
- 溢出触发点：
  - 叠适 content 内同步检测（卡牌结算后）
  - `damageEnd` / `loseHpEnd` 触发器兜底（非卡牌导致的体力下降）

## 二、破魔

> 当你使用的【杀】或单体锦囊牌被抵消后，你可判定，若为黑色则你可弃置一张牌，视为打出一张同名牌（不可响应）。

### 2.1 触发条件

| 条件 | 说明 |
|------|------|
| 你使用的牌被**无懈可击抵消** | `eventNeutralized` 触发 |
| 牌的类型 | 杀 或 单体锦囊（`targets.length === 1`） |
| 非延时锦囊 | 延时锦囊不触发破魔 |
| 杀被闪避 | **不触发**（闪避 ≠ 抵消） |

### 2.2 不触发的情况

| 情况 | 原因 |
|------|------|
| 杀被闪避 | `shaMiss` 事件，非 `eventNeutralized` |
| AOE（南蛮/万箭）被无懈 | 非单体锦囊 |
| 铁索重铸被弃 | 重铸 ≠ 使用 |
| 延时锦囊被无懈 | 走 `cancel` 路径，非 `neutralize` |

### 2.3 发动流程

```
1. 牌结算完毕（useCardAfter）
2. 弹窗确认 → 玩家选择是否发动
3. 判定一张牌
   - 红 → 无事发生
   - 黑 → 继续
4. 玩家选择弃置一张手牌/装备区牌
   - 不弃 → 取消
   - 弃置 → 继续
5. 自动打出同名牌（不可响应：`directHit`）
   - 对相同的目标使用
   - 杀：目标无法出闪
```

### 2.4 复制牌属性

- 打出的牌保留原牌的所有属性（名称、花色、点数、属性）
- 不可响应：加 `directHit` 标记
- 不加 `nowuxie`：复制牌**仍可被无懈**（v2 简化设计）

## 三、设计迭代记录

| 版本 | 改动 | 原因 |
|------|------|------|
| v1 | 初版 | — |
| v2 | 叠适不排除自己（桃/酒/无中自己也叠） | 设计确认：只要牌结算就可叠 |
| v2 | 延时锦囊触发改为 `lebuEnd` 等 | 裸名 `lebu` 不被引擎触发 |
| v2 | 杀叠适从 `shaHit` 改为 `useCardToEnd`（两段式） | 避免濒死前叠加导致溢出回血免疫 |
| v2 | overflow 从 `changeHpAfter` 改为 `damageEnd` + 叠适内检测 | `changeHpAfter` 在濒死前触发 |
| v3 | 破魔从「自动穿透 + nowuxie」改为「弃牌 + 不可响应」 | 削弱强度，简化实现 |
| v3 | 破魔限制为单体锦囊 | AOE 不触发 |
| v3 | 破魔红判定改为无事 | 降低收益 |
