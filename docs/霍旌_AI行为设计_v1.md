# 霍旌 AI 行为设计 v1

> 日期：2026-09-14  
> 武将：霍旌（`nihil_huojing`）  
> 实现：`nihilphile武将包/module/huojing_rewrite.js`  
> 状态：已实现，等待实战校准

## 1. 边界

这套逻辑只替电脑完成选择，不改变真人的规则与可选范围：

- 真人仍可在结束阶段取消【战帅】，或把“帅”交给任意合法角色，包括内奸；
- 真人仍可自行选择【遗忠】目标；
- 统计不显示标记，不产生日志、动画或额外结算；
- 【协攻】有合法【杀】时，电脑必定跟杀并优先打出价值最低者；失败交牌时优先交价值最低的手牌。

## 2. 累计数据与冻结快照

每名角色维护两层隐藏数据：

- `live`：本轮实时变化；
- `frozen`：截至上一完整轮末的全局累计快照，仅它能影响【战帅】AI。

下一次 `roundStart` 到来时，上一轮所有已登记角色（包括该轮没有出杀者）的数据并入累计值，`R` 增加1，然后生成新的冻结快照。这样霍旌在一轮中任何座次行动时，读到的都是相同样本，不会让本轮先行动者占便宜。

| 字段 | 含义 |
|---|---|
| `R` / `rounds` | 已完整参与并结算的轮数 |
| `U` / `uses` | 累计使用【杀】次数 |
| `H` / `hits` | 造成过正数有效直击伤害的【杀】次数；一张多目标【杀】最多记1次 |
| `D` / `damage` | 【杀】造成的有效直击伤害总量 |

霍旌自己的数据也会正常记录，但他永远不进入换帅候选。

## 3. 外部加伤归一化

只归一化用来判断“帅”人选的 `H`、`D`，不改变实际伤害和【军赏】摸牌：

1. 铁索传导伤害：伤害事件的 `notLink()` 为 false（父事件是 `_lianhuan` 或 `_lianhuan2`）时整段忽略；
2. 酒：从该【杀】的 `useCard` 事件读取 `jiu_add`；
3. 协攻：每次加伤时在同一个 `useCard` 事件累计隐藏字段 `_nihilXiegongDamageBonus`。

每次直击的有效伤害为：

```text
effectiveDamage = max(0, actualDamage - jiu_add - xiegongBonus)
```

只有 `effectiveDamage > 0` 才增加 `D`，并让该【杀】增加一次 `H`。一张多目标【杀】的每段直击都会累加 `D`，但整张牌仍只增加一次 `H`。

这是有意采用的保守归因：若酒或协攻加伤同时遇到减伤，无法从最终伤害中唯一还原“哪一部分被减掉”，实现会优先剔除外部加伤，可能略低估角色自身伤害，但不会把酒或协攻收益误算成武将能力。武将技能和装备自身造成的加伤保留。

## 4. 评分

从冻结累计值计算：

```text
Ū  = U / R
U* = Ū / 0.8
D* = D / H
score = 2 × U* + 3 × D*
```

- `0.8` 是普通角色每轮出【杀】次数的基准；
- 伤害能力比出杀能力更重要，权重为 `3:2`；
- 不计算命中率，也不对高值使用 `min` 或封顶；
- `U = 0` 时没有候选证据，得分为0；
- `U > 0` 但 `H = 0` 时，暂以普通【杀】的 `D* = 1` 作为先验。霍旌的协攻提供近似强命能力，因此不因既往闪避率直接惩罚候选。

## 5. 换帅规则

电脑只比较仍存活、霍旌态度为正、实际身份不是内奸、且拥有出杀样本的非霍旌角色。

- 霍旌是当前帅：选择合法候选中分数最高者；没有候选则不转；
- 其他角色是当前帅：现任也参与同一评分。另一友方必须严格更高才换帅；同分优先保留现任帅；
- 其余同分按霍旌当前态度、座次顺序稳定处理；
- 帅传出后，霍旌不会通过结束阶段主动拿回；只有现任帅死亡时，霍旌按技能规则重新成为帅；
- 内奸为硬排除项，不依赖当前公开身份或态度。这是按角色设计要求使用的AI内部信息，真人选择不受限制。

## 6. 遗忠规则

电脑选择【遗忠】目标时：

1. 当前存活的帅不是内奸、且尚无【协攻】时，优先传给帅；
2. 否则在非内奸友方中按态度选择；
3. 没有正收益目标时可以取消。

## 7. 回归场景

- 当前轮实时暴涨不会改变本轮的换帅判断，下一次轮开始冻结后才生效；
- 零出杀轮会增加 `R`，从而降低长期平均出杀数；
- 多目标【杀】累加多段 `D`，但只记一次 `H`；
- 酒、协攻加伤与铁索传导均不进入 `H`、`D`；
- 武将自身或装备的加伤仍进入统计；
- 内奸即使分数最高、态度为正也不会成为AI选择的帅或遗忠目标；
- 霍旌有很高统计分也不会成为结束阶段的候选；
- 现任帅同分时不换，另一友方严格高分时才换；
- 真人手选不受上述AI筛选影响。
