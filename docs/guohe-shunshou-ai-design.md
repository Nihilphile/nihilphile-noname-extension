# 过河拆桥 / 顺手牵羊 AI 行为设计文档

> 版本：v1
> 日期：2026-06-30
> 适用范围：通用（非 Tia 专属），当前在 Tia 模块中先行试点实现

---

## 一、设计目标

让 AI 在用过拆/顺手时有明确的优先级分层，核心原则：

> **拆牌不是为了拆而拆，而是为了创造/消除攻击窗口。**

---

## 二、优先级分层体系

优先级从高到低，数字越小越优先。每层内部通过"进攻/防守倾向"微调。

```
第1层（战术质变）        得分 ~100        Priority 1
├─ 拆+1马 → 从打不到变打得到
├─ 拆武器/-1马 → 从对方能打变打不到（完全消除威胁）
└─ 同时满足 → 按进攻/防守倾向选

第1.5层（破防）          得分 ~85         Priority 1.5
└─ 敌方有防具（八卦/仁王/藤甲/白银狮子）

第2层（战术优势，无质变）  得分 ~60-72      Priority 2
├─ 拆+1马（已在射程内，拆了也无法解锁新目标）
├─ 拆武器/-1马（拆了对方仍能打到你）
│   子排序：强武器 > -1马 > 弱武器
└─ 同层按进攻/防守倾向微调

第2.5层（手牌压制）      得分 ~35-55      Priority 2.5-3.5
├─ 对方手牌 <= 2 张 → 2.5
├─ 对方 3-4 张 → 3
├─ 对方 5-6 张 → 3.5
└─ 对方 >6 张 → 不拆

第3层（保留不出）         order->2        Priority 4
└─ 黑色过拆/顺手留手（Tia 专属）
```

---

## 三、各层详细规则

### 第1层：战术质变

#### 3.1.1 拆 +1马 解锁攻击距离

**条件**：
1. `!player.inRange(target)` — 当前打不到目标
2. `target.getEquip("equip3")` — 目标有 +1马

**逻辑**：拆掉 +1马 → 获得攻击窗口，质变。

#### 3.1.2 拆武器/-1马 消除威胁

**条件**：
1. `target.inRange(player)` — 目标当前能打到玩家
2. 目标是武器（equip1）或 -1马（equip4）

**完全消除 vs 部分削弱**：

| 情况 | 判定 | 优先级 |
|------|------|:---:|
| 有武器，无 -1马，getAttackRange() <= 2 | 去掉武器后大概率打不到 | 1 |
| 有强武器 | 去掉仍可能打到 | 2（子排序高位） |
| 有 -1马 | 去掉仍可能打到 | 2 |

#### 3.1.3 进攻/防守倾向调节

| 倾向 | 依据 | 范围 |
|------|------|:---:|
| 进攻倾向 | 场上是否有残血敌人 | 0.5-0.85 |
| 防守倾向 | 自身血量 | 0.5-0.9 |

- 自身残血 → 防守优先：拆武器/-1马保命
- 敌方残血 → 进攻优先：拆防具/+1马斩杀

---

### 第1.5层：破防

**条件**：敌方有防具（equip2：八卦阵、仁王盾、藤甲等）。

**白银狮子特殊处理**：目标已受伤 → 得分考虑回复效果，正收益时不拆。

---

### 第2层：战术优势（无质变）

#### 拆 +1马（已在射程内）

`player.inRange(target)` 已为 true，拆了无质变。

#### 拆武器/-1马（威胁已在但无法完全消除）

**强武器定义**（优先拆）：

| 武器 | 条件 |
|------|------|
| 诸葛连弩 | 无条件 |
| 青龙刀 | 无条件 |
| 贯石斧 | 无条件 |
| 雌雄双股剑 | 目标性别 != 使用者 |
| 麒麟弓 | 使用者有 -1马 |
| 羽扇 | 使用者有藤甲 |

**子排序**：强武器 > -1马 > 弱武器 ≈ 宝物

---

### 第2.5层：手牌压制

| 手牌数 | 优先级 | 得分 |
|:---:|:---:|:---:|
| 0 | — | 0 |
| 1-2 | 2.5 | ~55 |
| 3-4 | 3 | ~45 |
| 5-6 | 3.5 | ~35 |
| >6 | — | ~15 |

---

### 第3层：黑过拆留手（Tia专属）

条件：过拆/顺手为黑色 + Tia防御资源不足 → `mod.aiOrder`降至2。

---

## 四、友方目标

| 优先级 | 场景 |
|:---:|------|
| 最高 | 拆有害判定牌（乐不思蜀、兵粮寸断）|
| 次高 | 拆闪电 |
| 不拆 | 其他装备和手牌（返回负分）|

---

## 五、顺手牵羊额外加成

同一套优先级，顺手额外加分（不改变层级，仅层内微调）：

| 场景 | 加成 |
|------|:---:|
| +1马解锁攻击 | +8 |
| 武器消除威胁 | +5 |
| 防具 | +3 |
| 武器/+1马 | +2 |

---

## 六、Button AI 函数结构

```
tiaGuoheButtonScore(button, player, target, isShunshou) -> number

流程：
  1. 无法弃置 -> 0
  2. 判定牌 -> 按判定规则
  3. 敌方 -> 逐层检查（第1层 -> 第1.5层 -> 第2层 -> 第2.5层）
  4. 友方 -> 优先有害判定，其他负分
```
