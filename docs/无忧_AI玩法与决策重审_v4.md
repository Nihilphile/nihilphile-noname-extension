# 无忧 AI 玩法与决策重审

2026-10-13。用户要求先审玩法，再讨论代码。当前 v4 未提交实现已停止，未同步原工作区，最后修改未完整复验。本稿是新的策略约束，不表示这些行为已经实现。

## 1. 本次否定的设计

旧设计把过多“不知道”转换成“不安全”，又把“不安全”转换成“不发动、不出牌”。当前候选确实存在这样的接线。错误不只是新牌模型缺失，部分来自继承的 v3 风险政策。

应废弃以下通用硬规则：有响应技能标签便把整个目标的效果视为未知；有未知救援便不计合理斩杀机会；普通未知手牌使可靠获胜例外永久失效；低血时不许将任一花色从二忆花至一忆；模型预算不足默认不使用原牌；存在友伤时只有伤害分为正才允许用其他收益补偿。

确定不合法、已知无效、真实负收益仍可拒绝。普通手牌未知、具体估值不够精确、技术计算失败必须分开处理，不能冒充同一种“负收益”。代码故障需要修复，不能靠禁用有问题的技能分支宣称完成。

## 2. 无忧的实际打法

无忧需要把当前手牌兑现为用牌收益，并通过同色重铸、响应、弃置等非使用失牌补忆。追还用少量不同花色的忆扩大这一张牌的收益；恍惚则用一整种花色的忆抵消伤害牌对自己的效果。攻防共用忆，但两个技能的消耗方式不同。

### 出牌与朦胧

在本人出牌阶段，以自己手牌为材料使用牌时，每个花色要比较“选哪张使用、其他同色牌会被重铸”的整组结果。不能把同色两张普通牌都当成稍后还能使用，也不能只看单张牌的原生优先级。

优先处理实际紧迫的救命、解除限制和高价值斩杀。普通情况下，能获得新资源的无中、顺手等值得提前考虑，但若会重铸同色的救命桃或关键斩杀牌，也要计算损失，不能固定规定无中先于所有杀。不同花色仍可连续使用，每张结算后重新评价；新摸回同花色的牌不是本回合永远禁用。

不用牌的正当理由应是有具体代价，例如会重铸掉唯一救命牌且当前进攻不足以弥补。不能以“追还不值得花忆”推出“这张牌不值得用”。反过来，原牌单独价值较低但追还能产生足够收益，也可以主动使用，例如铁索的多目标取牌、无法匹配花色的火攻取牌。

### 忆的保留与消耗

| 当前资源 | 默认倾向 | 必须进一步考虑 |
| --- | --- | --- |
| 总共只有一忆 | 普通小收益先攒 | 当前能否救命、显著提高获胜机会；不能为了让技能发动而硬花 |
| 有若干颜色，每色一忆 | 按可支付颜色组合比较 | 三色、四色的二档成功率大幅不同，不能都贴上“末忆”后拒绝 |
| 某色二忆 | 按实际需要给恍惚资格定价，不固定高价保留 | 血量健康、剩余有效防御足够时，二变一可积极用于进攻；防御缺口、近期威胁和本次后续补忆决定附加成本 |
| 某色三忆及以上 | 每次花一忆通常更积极 | 三变二仍保留防御资格；不能库存越多反而一直等待完美机会 |

后续补忆只能影响机会成本，不能预支支付时尚不存在的忆。若花掉第二忆后，本次决斗就可能致死，不能拿尚未发生的重铸当救命能力；若本牌无此即时危险，并会在下个敌人行动前补回储备，则不应仍按失去整轮防御收费。

用户进一步明确：血量健康且手上防御充足时，不必特别保留恍惚。防御储备应按本牌结算后、到下次行动前的实际防御缺口定价；已有手牌和防具能覆盖普通威胁时，恍惚的附加储备成本可以很低。忆的未来追还用途仍有价值，但不能再额外统一收取高昂的“恍惚资格费”。防御牌只计算实际合法且适用的响应，扣掉本次使用、响应及同色重铸会失去的牌；强命等公开威胁会降低相关防御牌的覆盖作用，不直接变成禁止进攻。

### 恍惚

少于二忆时，普通情形移除忆不能取消目标，不发动。有廉价、合法且可靠的响应时，比较响应消耗与整色忆消耗；响应还可能补忆。面对强命、连续伤害或濒死风险时积极考虑取消。库存六忆时恍惚要花六个，不能套用追还只花一个的成本。

## 3. 追还主要是在买哪一档

按四花色独立等概率的公开先验，精确枚举翻牌花色得到下表。这是决策近似，不是读取剩余牌堆后的真实概率。

| 支付不同花色数 | 至少一档 | 至少二档 | 至少三档 | 四档 |
| --- | ---: | ---: | ---: | ---: |
| 1 | 25% | 0 | 0 | 0 |
| 2 | 75% | 12.5% | 0 | 0 |
| 3 | 98.4% | 65.6% | 9.4% | 0 |
| 4 | 100% | 98.4% | 65.6% | 9.4% |

因此，四色各一忆配合群体牌，常常是在买接近确定的二档取牌和可选择的三档，而不是主要押四档。四档只是附加机会。普通单目标牌只有一个适合追加的目标时，付一色与付更多颜色则应按额外收益分开比较。

### 两花色争取追加是常规进攻方案

支付两花色各一忆，至少命中一档的概率为75%，相比只付一色的25%，多一忆带来50个百分点的追加成功率；另外有12.5%的概率解锁二档。不能把第二枚投入只看成更贵，却漏掉成功率的跃升。

若本牌结算后血量健康、防御仍够用，并有明确有价值的合法追加目标，应积极比较两花色支付。例如桃额外治疗队友、无中额外给队友摸牌、顺手再取敌牌，以及杀/决斗追加合适敌人。允许花掉某色第二忆，也允许使用两个各只有一忆的花色；总共只有一忆通常保留的规则不能套到这里。

具体决策顺序是：先找最佳追加方案，再估计其净收益，比较零付、一色、两色及其他合法组合的期望收益和实际储备成本。两色方案可按“62.5%仅解锁一档的最佳收益 + 12.5%解锁至二档的最佳组合收益 − 支付成本”估算，未命中时无升级收益。二档有害就取消，不能因其有害否决一档。目标反伤、距离、免疫及队友需求均进入净收益，不把75%命中等同75%造成伤害。

两色不设置抢先返回：若多投第三色的收益大于新增成本，仍可选三色；群体牌没有新合法目标时，不能用75%的追加概率虚算收益，应另比较二档及以上。仅一个普通追加收益时，也不能默认选四色把成本放大。

取敌牌有己方得牌、敌方失牌两份价值。取队友牌首先是队内重新分配，基础阵营牌差为零，实际代价取决于是否拿走其关键防御、谁能更早使用、是否溢出，以及无忧后续重铸。不能统一扣一个很大的负分，压掉整个群体取牌档。

多档必须联合比较，但每档独立可取消。三档会伤害队友时，可以选二档而关闭三档；铁索四档抵消横置价值时，二加四仍可能因为两轮取牌而值得。支付已发生后，不再因为“本来不该付忆”拒绝眼前有收益的免费选项。

## 4. 三层决策树

```text
当前有合法牌/目标吗？
  没有 → 正常结束或交回原生其他行动
  有 → 为候选保留三种结果
         A. 原牌 + 实际重铸，追还不发动
         B. 原牌 + 可选追还策略 + 实际重铸
         C. 保留这组牌，选择其他行动或停手
       比较整组收益和具体风险，选择当前最佳行动
       未知不删除 A；技术失败回原生合法出牌判断
  ↓ 真正使用牌
比较不支付与各合法花色组合
  收益不足、具体储备需求更高 → 不支付，原牌继续
  某组合净收益更高 → 支付该组合
  普通未知手牌/救援 → 估概率，不直接拒绝整个技能
  ↓ 翻牌结果已知
枚举已解锁选项组合，保留已确定的前序选择
  选择当前收益最高的合法组合，可全不选
  某目标/某一档不确定，不连带删除其他明确有益的档
  ↓ 实际结算、补忆、重铸
更新全部资源，再选择下一张牌
```

“紧急”“积攒”“余量多”只是改变比较权重，不是进入后就一直返回的排他分支。低血不自动停止进攻，忆多不自动开启友伤，原牌正收益也不掩盖重铸救命牌的成本。

## 5. 风险如何进入决策

敌方未知手牌按公开数量、公开转换能力及已知牌估算，不视为全部杀、闪、无懈或桃。决斗零手牌且无公开可用的替代响应材料或能力时，不需要无忧自己有杀；仍须检查装备转杀等来源。一至二手牌属于常见可尝试目标，不强求三档。原目标、追加目标和第二轮必须共享无忧剩余杀。

技能标签接口的内部实现有时会检查隐藏手牌花色，因此“查询返回可转杀/可转闪”本身不一定是公开事实。判断依据应是公开技能规则、公开装备及手牌数量，隐藏材料仍用估计，不能借标签接口间接读取敌手牌。

救援可能降低击杀概率，但不能把所有濒死敌人恢复成一血、抹掉制造濒死和消耗救援的收益。需要区分高把握获胜与规则确定获胜；普通决策用前者，只有声称必胜时才要求后者。影响结果的公开特殊能力只作用于对应牌效，转闪不能让决斗的取牌也消失。

友伤按用户偏好纳入整个结果：有较大把握获胜可以接受队友死亡；普通一敌换一友通常避免；击杀敌方伴随非致命友伤可以尝试；两敌换一友也进入比较。两敌各受一伤、一名健康队友受一伤的普通 AOE 不能被统一门槛自动判死，要看剩余血量、防御、夺牌、回合顺序和继续进攻能力。

比较追还风险时只算它相对原牌新增的部分。原牌已经存在的同一未知响应或救援风险，不得再次记为追还制造的风险。顺逆序等可由本方选择的决策应主动选优；不能把可控选择伪装为必须承受的最坏随机结果。

技术失败不应产生一个貌似战术判断的“不出牌”。决策记录必须区分明确负收益、具体资源保留、普通信息估算、模型缺口和运行故障。模型缺口采用局部估计或原生判断，运行故障进入修复清单，不能算作策略成功。

## 6. 用于检验设计的普通局面

| 局面 | 应出现的行为 |
| --- | --- |
| 没有忆，但有正常可用的无中、顺手、杀 | 正常比较并使用，不要求追还有正分 |
| 总共一忆，杀可追加普通高血敌人，无紧迫斩杀 | 通常保留忆，原来的杀仍可照常使用 |
| 无忧三血、防御足够且不会被本次重铸耗掉，有两种花色各二忆；使用无中，有合法队友可追加 | 两色支付应成为积极候选，不为机械维持两色恍惚资格而拒绝；按75%额外给队友摸牌的机会计算，二档队友移牌可取消 |
| 无忧血量健康、防御足够，只有两种花色各一忆；桃可同时帮助自己和追加的受伤队友 | 正常比较两色支付，不套用“全身仅一忆先攒”的默认规则；确有治疗需求时，75%追加机会可覆盖投入，仍与保留忆价值比较 |
| 四色各一忆，2v2 群体牌预计能从两个敌人各取一牌，队友并不缺这张防御 | 四色支付应能进入实际优选，不能因“每色末忆”提前拒绝；最终仍计算重分配及储备代价 |
| 每色三忆，有两名持牌敌人的铁索 | 积极比较以二档取牌为主要目的的用牌；不能要求铁索先有直接伤害收益 |
| 无忧三血，追加决斗敌人零手牌，自己没有杀 | 翻出一档后应优先考虑追加，除非公开免伤、装备转杀或其他替代响应改变结果；支付前另看忆成本 |
| 无忧三血，轮到追加目标时余一杀，敌方两张未知手牌 | 计算对方有两次杀响应的概率，允许有利时尝试；不能因可能反伤而直接拒绝 |
| 无忧低血、红桃二忆，红桃牌结算后会安全重铸两张红桃杂牌 | 追还可使用当前已有红桃忆，计入本次后续补回储备，不能命中硬保留分支；先排除重铸前就有致死风险 |
| 火攻缺匹配材料，但目标持牌，追还二档已解锁 | 伤害可能为零，正常 End 的取牌仍可选；不能把火攻失败等同整个技能无收益 |
| 队友有转闪技能，AOE 的二档只增加取牌、不增加该队友伤害 | 根据真实防御与移牌价值评估，不能把技能标签变成整张牌的未知败局 |
| 无忧一血、四色各二忆，两敌各一血且空手，普通杀追加即可依次解决两敌；队友有一张未知手牌 | 在无其他公开防御/救援能力的假设下，三色支付的一档成功率约98.4%，应认真选择立即争胜；队友这张无关未知手牌不能取消胜局估值，更不能再触发绝对保留第二忆。此例为静态推导，未作实测 |

这些是审查场景，不是本轮实测结果。验收应使用完整合法目标、常见血量和库存，并同时检查用牌、支付、后缀。高血量和大量忆只能证明理论可达，不能证明普通玩法合格。
