# 无忧 AI 初版对抗审查

2026-10-11。独立审查者 `wuyou_design_adversary`，按用户要求只派一个设计审查子代理。对象为《无忧_AI决策树_工程初案_v1.md》修订前版本及当前无忧机制源码。仅审查，没有运行对局。

审查问题是各分支是否有实际收益，以及高优先级分支是否长期支配其他分支。主控接受以下两项阻断，并在实现前修订原方案。

| 发现 | 具体反例 | 裁决与修订 |
| --- | --- | --- |
| 无条件保护导致保牌互锁 | 2/3血，同为红桃的桃、闪、杀。用桃洗闪，用杀洗桃闪；两者都被否决，只能停手等受伤至1血 | 接受。实际回血始终可进入比较；健康保护牌改为有限成本3；仅危险状态的唯一保命牌对普通攻击保留硬保护 |
| 重铸成本忽略停手必弃牌 | 3血，五张梅花杀、决斗、过河、连弩、八卦都有正收益，原公式让所有用牌净分非正，停手后却必须白弃两张 | 接受。出牌与弃牌共用实体留牌计划；停手时必弃牌重铸边际成本0.25，不再按可用牌2分完整扣除 |

实现必须有三个可达性见证：2血同色桃闪能回血；健康状态同色关键闪不无条件封锁高收益攻击；五张同色牌、手牌上限3时不全体停手。每个见证都需验证实际动作后重算，而不是一直保留旧分支。

用户随后确认同色只选当前收益最高的一张，其余都被强制重铸。主控据此收紧模型：每个有效花色产生一个合法最佳动作，普通保留牌只计1分持有价值，必弃牌0.25，保护牌3，不把其余同色牌的各自行动收益叠加为成本。这样2血同色桃闪杀即使库存已跨2忆门槛，也有0.4回血净收益，不需要人为给回血分支兜底正分。响应与未知转换不误用此分组规则。

审查确认追还概率表正确。在两名健康敌人可攻击且有足够手牌时，普通杀的各匹配数最优增量为 `[0,1.2,4.8,6.4,14]`。三色各1忆净收益1.59375，健康状态四色各2忆净收益0.50625，都高于0.25，因此追还总体可达。

不调整以下保守拒绝：单色仅1忆的普通追加收益通常不足以付费；自用桃或无中没有合法额外目标时，仅9.375%的增次收益不够覆盖四色最低成本。不能为了让每档经常出现而让AI浪费资源。

设计没有要求“恍惚和闪都不用”。关键闪保护仅针对顺带重铸，普通响应仍可使用。实现需检查连续轨迹“健康普通杀下拒绝恍惚 → 实际出闪 → 响应素材加忆”，防止出牌保留分意外污染响应。

其他注意事项：回血和解判定优先必须绑定真实缺血与真实判定对象；结算后清除已不成立的条件。危险状态的忆预留属于明确取舍，应和上述出牌解锁同时实现。不把一局没出现某档推断为不可达；本版未接入运行时分支原因日志，实战只对公开行为作证。
