# 无忧 AI v3 三层设计审查

2026-10-12。对象：[三层设计稿](无忧_AI三层决策设计_v3.md)。本轮只交付设计，不修改生产 AI；不把文档审查当作机制测试或实战验收。

后续实现已完成；本文保留原设计阶段结论，最新代码审查与实机结果见[验收记录](无忧_AI_v3验收记录.md)。

用户要求的两个问题：每条决策分支是否有实际收益；是否真正可达，而不是被前置条件或某个常驻分支封死。审查还核对胜局、友死、普通击杀、友伤的交换规则。

最终复核结论：独立 Sol 确认已知设计阻断关闭，可交付设计稿。其最后提出的“普通交换算例须排除已终局”也已补入；该结论不代表代码已实现或实机通过。

## 参与与方案选择

- Sol A（`wuyou_v3_terminal_design`）：独立设计终局门与风险控制，核对身份/2v2、逐人死亡、AOE 方向选择。
- Sol B（`wuyou_v3_board_design`）：独立设计成对全场结果树、牌流/库存、资源势能及出牌入口。
- 独立 Sol（`wuyou_v3_adversarial_review`）：在合并稿上对抗审查，没有参与生产修改，也没有改写被审文档。

合并采用 A 的纯终局预测及顺序边界、B 的联合轨迹和库存势能。舍弃只评原生高分前两三张的剪枝，因为它会挡住靠追还才转正的行动；舍弃平均击杀数换算、各目标独立最大收益求和。

## 发现、复现与处理

| 发现 | 最小反例/证据 | 文档处理 |
| --- | --- | --- |
| 原生入口仍会封死增强后才正的牌 | 当前 `wyBuildSnapshot` 先过滤 positives，群伤含友即 false；`player_use` 仅可归零。改 order 不保证通过目标 AI | 第 5.1 节明确局部 phase `ai2` 适配，自动全目标唯一 anchor，原生合法性保持；要求真实选牌/选目标链验收 |
| 每个窗口移动基线会拆坏整体组合 | 首窗追加的敌死被后窗当成基线，友死交换补偿凭空消失 | 四窗共用支付后不可变 decisionRoot，prefix 只限制可行域 |
| 忆成本只看支付瞬间错误 | M=1、必重铸 G=1，机会成本实际 1.10，不是 .55；M=2、G=1 则是 .25，不是 1.10 | 成对轨迹延至 useCardAfter 重铸完成，分别用末端库存势能；中途防御仍按实际 M−S |
| 各匹配数最优不等于跨匹配数全局最优 | CVaR、90% 胜局门、80% 友死合格率非线性；逐 m 拒绝的动作可能在混合后满足门 | 明确后向归纳可执行条件政策：预演与真实 suffix 同函数、同 root、同排序，再对混合政策加支付门。不承诺全局最优，宁可错过部分跨 m 合算政策，也不预估实际会拒绝的动作 |
| 边际败率相减会抵消新增风险 | root 只在 A 败，候选只在 B 败，A/B 各半；边际差为零，新增败局实际 50% | 新增 LOSS 定义为配对事件 `candidate=LOSS 且 root≠LOSS`；击杀/友伤也逐路径取差 |
| 分别压缩结果树丢失相关性 | 两端各取 64 状态后再拼会错误识别新增敌死及 2:1 | 联合状态包含共享潜变量、两端状态与终局前缀；联合合并/截断，未知概率不归一化抹去 |
| 桃园把满血敌人算作可取牌 | 原生 ignoreTarget 在效果前跳过满血目标 | 算例改为所有相关目标均缺至少 2 HP，计敌方回血代价；第二轮再次检查 |
| 桃园取来的同色牌可能再重铸 | 取牌在效果末，强制重铸在整张牌 useCardAfter | +2.5625 改为限定下界：原手只有此桃园，未知牌等价 0.8，无其他触发/特殊保命价值；新增末端忆只增加该下界 |
| 无中并非在所有模式都固定两摸 | 原生对抗模式中目标一方存活人数较少可三摸 | 增加实际 drawCount 适配要求，普通两摸见证明确前提 |

审查者一度提出“标准 2v2 的 1v2 可以给友方三摸”的反例，复核后主动撤回：己方仅一人时没有可追加的存活队友。保留原生三摸事实，不保留这个无效反例或错误 PAY 断言。

## 收益与可达见证

[算术记录](evidence/wuyou-ai-v3-design/arithmetic.json)是设计参数的离线计算，不是对生产代码执行测试：

- 无后续忆变化的普通桃：末忆净 −0.05；三忆支付净 +0.25。末忆通常保存、余量分支可达。
- 普通友方无中两摸的简化无后续忆变化见证：末忆净 −0.15。实际出牌还须算本人摸牌引起的重铸库存变化，不能把简化成本固定套用。
- 四色末忆桃园，在文档限定条件下忽略新增忆的下界：付一/二/三/四色净值分别 −0.8、−0.95、+0.9、+2.5625；至少有正的多色支付候选。
- 普通一敌死换一友死：H 为 −3，拒绝。两敌死换一友死扣尾部后 +1.125，能进入资源成本比较；一敌死加非致命友伤为 +2.125，也能进入。均以公开可证明无救援/免伤、无提前败局、尚有其他敌人且未终局为前提；2v2 已杀光两敌时使用胜局分。
- 互斥路径中分别杀敌和死友，不能用平均人数凑 2:1。基线本已杀死的敌人不能再次支付升级新增的友死代价。

证明门有意保守：两敌换一友和直接胜局在救援/关键技能未知时可能不成立，当前窄见证只能证明分支真实可达，不能声称多数实局都会识别。普通非致命收益可以用公开手牌数先验排序，不能把它包装成可靠胜局概率。
