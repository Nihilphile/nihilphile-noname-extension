# Nihilphile 武将包 v1.1.0

本版以当前主包基线 `b5ddd3d` 为基础，包含现有武将、资源、此前落绯风险检查与性能优化，并合入 H01 延迟优化。下载 Release 附件 `Nihilphile-v1.1.0.zip` 后可在游戏中导入扩展。

## 落绯改动

扫描外部技能时，如果已读取的 `ai.effect` 不存在，就跳过该技能无关的 `ignoreSkill` 查询。存在 effect 时仍先查询 ignoreSkill，再取实际回调，保留动态替换回调的行为。

候选动作、搜索深度、态度层、实际出牌者和核心决策链保持原样。外部 effect 继续只参与保守风险检查。没有新增跨回调缓存，也没有实现尚在设想中的 hyw 标记。

AI 源码 SHA256 为 `93924ddb0100bc248c341cac150605ac89648ac8b4d4650780a5b403b25b5521`，与此前隔离验证的 H01 完全一致。规则模块 SHA256 仍为 `1ac47f139f2f152d64e6c9d24989c2c95a69c9e77df1a8540757f3d7479982e4`。

## 合入后的性能复测

使用原冻结测量程序，比较合入前备份和当前主包。四种八人六手牌场景各预热一对，再交替运行五对正式样本，保留全部结果。

指标为每个出牌阶段中最慢一次完整选择累计消耗的同步 AI 调用时间。下表是五次中位数，方括号为最小值至最大值，单位 ms。它不是单次 API 延迟，也不是界面等待时间。

| 场景 | 合入前 | H01 | 中位数变化 |
| --- | ---: | ---: | ---: |
| 纯白板 | 1002.5 [917.4, 1048.4] | 992.3 [969.7, 1063.0] | −1.0%，不作改善结论 |
| 良性 effect | 2070.7 [1935.3, 2246.5] | 1695.6 [1468.0, 1979.8] | −18.1% |
| 使用者出杀惩罚 | 1860.8 [1785.5, 2116.2] | 1378.8 [1363.1, 1467.0] | −25.9% |
| 目标反击风险 | 1981.2 [1803.3, 3148.3] | 1374.2 [1362.4, 1466.9] | −30.6% |

含预热共 48 个原生出牌阶段、24 对，身份、初始局面、动作、实际用牌者、目标、决策及最终状态逐对一致。40 个正式阶段覆盖 240 次完整选择、4060 次计时回调；全部归属完整，零异常、零超时，隔离会话已停止，源码前后哈希一致。

测量机器为 Ryzen 7 5800H、16 逻辑处理器，开始和结束 CPU 负载分别为 25% 和 5%。这是共享机器上的有限固定场景结果，计时可能包含系统抢占或 GC。主要节省来自减少风险探测中的无关技能查询，其他状态采集与搜索仍需执行。不能据此保证任意实战、每次调用或尾延迟都有改善。

汇总数据及原始记录哈希见同目录 `v1.1.0-latency.json`。本机原始证据、测量程序和合入前备份保存在 `.audit/h01-release-20261015/`。

## 本地验证与发布检查

- 25 个可独立解析的主包 JavaScript 文件语法检查通过。两个历史拼装片段未作为独立文件检查。
- 20 个可移植测试脚本通过。
- 落绯既有决策、winner、运行时和行为回归共 182 项通过；外部风险检查 22 项通过；H01 专项 7 项通过。
- 纯白板对照覆盖 10 个场景、12 次决策或原生选择及三步决策链，全部通过。
- 选将检查覆盖 6 个场景，每个重复加载 3 次，全部通过。

首次执行可移植测试时，无忧加载测试仍期待落绯保持临时 AI 禁选。已按此前完成的选将修复更新四处旧断言，保留无关禁选和殷华禁选检查，随后全部通过。本版没有为该测试改变加载逻辑。

发布流程改为显式测试清单，并检查所有顶层测试入口无遗漏、无重复。GitHub Actions 执行 20 个可移植脚本；14 个依赖外部引擎的脚本、一个 benchmark 和一个夹具模块单独分类。云端结果不能代替本机原生验收，本轮只重跑了其中受落绯改动影响的检查。

包内版本统一为 `1.1.0`，根目录 `验收记录.md` 保留历史记录并补充本次状态。Release 的 ZIP 与 `SHA256SUMS.txt` 由标签源码生成，流水线逐文件校验归档。

## 验收边界

本轮未新增完整随机实战或人工验收，不把固定场景的 48 个阶段算作 48 局。其他武将沿用基线状态，未全面重新验收。既有 dead/out 搜索模型覆盖缺口仍保留。

无 effect 技能不再执行其无关 ignoreSkill 查询，因此也不保留该查询自身的副作用、日志或异常。伪技能只改变 AI 提示，没有实际扣血效果；effect 数值不是扣血量。这次发布不修改本机已安装的游戏目录。
