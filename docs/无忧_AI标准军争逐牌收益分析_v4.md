# 无忧 AI：标准与军争逐牌收益分析 v4

2026-10-12。按用户最新范围，只分析标准与军争，暂不实现。牌源为本地测试引擎 `card/standard.js`、`card/extra.js`；追还规则以原工作区 `nihilphile武将包/module/wuyou.js` 为准。国战、应变及其他牌包不在此次范围。

标准与军争共有 16 个基本牌/普通锦囊牌名。酒按用户要求跳过，闪、无懈沿用此前跳过要求，余下 **13 个牌名全部列入分析**。火杀、雷杀作为杀的属性分支。装备、乐不思蜀、兵粮寸断、闪电不属于追还可触发的这两种类型。

当前 v3 仅适配杀、桃、无中、桃园、南蛮、万箭、过拆、顺手；决斗、火攻、铁索、五谷、借刀仍未实现。本文中的预期行为与组合分析，不代表这些缺口已经补齐。

## 1. 四档究竟改变什么

| 档位 | 实际操作 | 估值边界 |
| --- | --- | --- |
| 一档 | 给原牌额外指定一名合法目标 | 计算新增目标的整套结算及其后续取牌，使用原生合法目标/距离检查。不能把辅助目标当作独立受牌目标。 |
| 二档 | 每名目标每次牌效果正常结束后，随机获得其一张手牌 | 按结算后的剩余手牌计算；不是从牌堆摸牌，不是任选手牌。死亡、空手、整次效果被取消/跳过时不能凭空获得。 |
| 三档 | 将所有在场角色加入该次用牌的不可响应名单 | 基本牌/锦囊各有不同响应逻辑；普通锦囊还会封住全桌无懈，包括己方救场。不能绕过所有防具和技能。 |
| 四档 | 此次牌的效果次数加一 | 第一整轮目标结算完再进行第二轮。沿用已变动的血量、护甲、手牌、装备、横置状态；不是把第一轮收益乘二。 |

四档是依次解锁的可选项，**达到四档并不要求把前三项全选上**。二档和三档一旦开启，会作用于整次用牌，不能只对敌人取牌、只让敌人不可响应。

“同花色择一”是无忧本人出牌阶段的强制重铸约束。神落绯用自己的牌让无忧使用时，不能直接假定会重铸无忧同花色手牌：追还判断用牌者，而朦胧还要求本人出牌阶段和本人手牌材料。操控也不等于改变无忧的阵营，追还仍从无忧的友敌关系计算收益。

### 共用的收益口径

- 从敌人获得一张手牌，同时有己方得牌、敌方失牌两个收益；敌方的最后一张防御牌通常更重要。
- 从队友获得一张手牌，阵营总牌数不增加，是资源转移。一般比取敌人牌收益低，但不能一律固定判负：要看谁能更早使用、队友是否缺防御、双方是否溢出、无忧拿到后是否会被强制重铸。
- 从自己手中获得自己的牌没有实际牌差。技能代码会尝试自取，但原生获得流程不产生实际移交和失牌加忆，资源估值为零；不能据此声称整个 gain 事件或任意扩展的获得牌触发都不存在。
- 伤害按实际血量、护甲、藤甲、白银狮子、属性连环与救援分支计算。扣敌方护甲也有收益，损己方护甲也有成本。
- 一级加入的人会同时承受二至四档。先选一个目标，再分别挑选能提高最终净收益的其他选项。
- 支付忆只扣一次。原牌本身的收益用于决定是否出牌；追还支付用“原牌带升级”减“原牌不升级”的增量，不能再次计入原牌的固定收益。

## 2. 十三种牌逐档分析

表中“高/低”仅说明收益来源，不是硬编码常数，也不是所有局面都成立。正常全体牌的一档通常为零，是因为合法目标已经在原目标列表内，不是因为它们都被引擎标记为 `multitarget`。

| 牌 | 一档：追加目标 | 二档：结算后取手牌 | 三档：不可响应 | 四档：多结算一次 |
| --- | --- | --- | --- | --- |
| 杀，含火/雷杀 | 多一次针对新目标的杀。斩杀、压关键敌人收益高；要算防具、距离和属性连环。 | 从存活且有余牌的目标取一张。对方出闪后仍可取，但出闪导致空手则取不到；直接击杀后也取不到。 | 把可闪分支变成受伤分支，关键在增加命中/斩杀概率。原本已强命或目标无响应时增量小；防具取消仍可能生效。 | 第二轮再杀，不多消耗一张杀。第一轮耗闪和取牌可提高第二轮命中；不能对死亡目标再算伤害。属性杀第二轮连环结构可能已经变化。 |
| 桃 | 给合法的受伤队友额外治疗一血，可高于普通拆牌；危急治疗价值更高。不能给满血角色虚算治疗。 | 原目标通常自己，自取零收益；追加队友后取的是队友手牌，通常较低，缺防御时有害。 | 普通桃没有闪/杀/无懈响应需求，基线增量为零；特殊技能另外判定。 | 再回复一血，按剩余失血封顶。只缺一血时第二次治疗为零。普通桃没有桃园的健康目标跳过逻辑，若二档已开，第二轮治疗无效也不能直接推断其 End 取牌不存在。 |
| 无中生有 | 额外给队友摸牌，通常很有价值。正常两张；本地特定对决规则可能三张，须读取实际摸牌数。 | 自取零；追加队友时把其摸到/原有的一张转给无忧，通常低于从敌人取牌，按分配需求判断。 | 防止敌方无懈，使摸牌和后续 End 得以执行。没有可能无懈时增量接近零，不能永久记零。 | 各原目标再摸一轮牌，通常高收益；满手溢出和后续重铸会降低具体价值。 |
| 过河拆桥 | 再拆另一目标一张，敌方关键装备或手牌收益高；也可拆队友负面判定。 | 原牌拆完后仍有手牌，才再取一张。对敌人往往有可观收益；只有一张手牌且被先拆掉时为零。 | 防无懈，保证拆关键牌和后续取牌。无懈概率低时不应凭空加很多分。 | 第二轮再拆剩余区域中的一张。需要重新选区域、考虑先前拆装与取手后的库存；有足够牌时可形成“拆两张、取两张”。 |
| 顺手牵羊 | 对距离内另一合法目标再拿一张，可拿敌方关键牌或帮助队友移除负面判定。 | 原牌拿完后，再取目标剩余的一张手牌；敌方牌差收益高，手牌被拿空则为零。 | 防无懈，保住原生获得及 End 取牌。 | 第二轮按剩余区域再拿一张，并可再触发二档；库存充足时总共获得四张，不能在库存不足时仍按四张计。 |
| 决斗 | 多打一场决斗。必须共享无忧实际剩余杀，不能每个目标都假设无忧有同一批杀。可能追加敌人反而让无忧受伤。 | 无论决斗谁受伤，只要效果正常结束、目标存活有手牌且无忧还能完成取牌，就有机会取一张；之前双方打出的杀要先扣除。 | 很重要。目标先响应；不可响应使其不能打出第一张杀，通常直接受伤，无忧也不用跟杀。除提高命中，还节省无忧杀、降低反伤风险，并防无懈。 | 再进行一次完整决斗，沿用第一轮耗杀和二档取牌后的库存。与三档合用通常是重复强命伤害；不开三档可能把无忧拖进第二轮反伤。 |
| 火攻 | 对另一个有手牌的目标再火攻；要分别付出匹配其展示花色的弃牌，不是免费多打一伤害。 | 即使没弃出匹配牌、没造成伤害，正常结束后仍可取目标一张。目标仅一张手牌时，第一轮取走会削弱第二轮火攻。 | 主要防无懈，不会免除目标展示、自己的同花色弃牌，也不会直接保证伤害。 | 再展示、再决定弃匹配牌。要扣第二次弃牌成本，并考虑首轮夺牌改变目标手牌、自己新获得的牌与忆、火伤连环状态。 |
| 铁索连环 | 追加第三个合法目标，可能多连一个敌人或解开一个队友。价值取决于当前横置状态及后续属性伤害机会。 | 每个实际正常结算且有手牌的目标各取一张；可以主要为多目标取敌方牌而发动，不要求连环本身收益很高。 | 防无懈，保证所选横置/重置与取牌。不会立即带来伤害；也会封住己方对不利目标的无懈。 | 无中途变化时，横置状态翻转两次，回到用牌前；因此可能抵消第一轮的好处。与二档结合可取两轮牌，仍可能值得开，不能一律拒绝。 |
| 桃园结义 | 正常已经覆盖全体，一档无新合法目标。 | **只对本次效果确实执行的受伤目标取牌**。健康目标被 `ignoreTarget` 跳过，不能算全场各取一张；从受伤敌人取牌与从受伤队友取牌分别计价。 | 防无懈，使治疗和取牌更可靠；但也保证敌人的治疗，并阻止己方对敌方治疗使用无懈，可能为负。 | 第二轮只处理仍受伤者。缺一血者首轮回满后，第二轮治疗和取牌都没有；敌我治疗净值及二档实际人数一起计算。 |
| 南蛮入侵 | 正常已覆盖所有其他角色，一档通常无增量。 | 各目标打杀或受伤之后，按剩余手牌取一张；群体累计可很高，但扣掉取队友牌的代价，死亡和被防具整次取消者不能算。 | 敌我都不能打杀。能强制敌人受伤，也会剥夺队友防御；斩杀/可靠获胜可支持开启，否则可能应取消。还会封无懈。 | 所有目标再结算一轮，按剩余杀、HP、护甲判断。不能简单认定全场两点伤害；二档首轮可能进一步剥夺后续响应。 |
| 万箭齐发 | 正常已覆盖所有其他角色，一档通常无增量。 | 各目标出闪或受伤之后按剩余手牌取牌，多目标累计可高；有闪但只剩一张时，出闪后已无牌可取。 | 敌我都不能出闪，连同无懈一起限制。敌方斩杀收益与己方伤亡风险一起判断，不可只看敌人。 | 第二轮看真实剩余闪与防具等状态；三档加四档可形成两轮强命，但藤甲免疫等不会被三档自动绕过。 |
| 五谷丰登 | 正常已覆盖全体，一档无新合法目标。 | 先让目标取得五谷牌，再从其手中随机取一张。原本空手且此刻只持刚选牌时，必取这张公开牌；有其他手牌时按实际手牌混合随机，不能认定总拿走其刚选中的关键牌。 | 防无懈，既保证己方选牌，也可能保证敌方选到关键牌。必须看整轮选牌与取牌的净效果，不是纯收益。 | 原生会再次执行开池与收池流程，第二轮不是继续从第一轮空池取。所有人再选一轮牌；与二档组合可再收一轮，但也有资敌与给队友移牌代价。 |
| 借刀杀人 | 设计收益是多一组“持刀者→受杀者”的出杀/交武器选择。但当前原生追加存在配对错位的函数级反例，修复前不能直接开放 AI 选这一档，见 WUY-AI-001。 | 从锦囊目标即持刀者剩余手牌取一张；不额外从被要求吃杀的人取。 | 持刀者不能执行要求的出杀，转入交出可获得武器；可利于夺刀，也可能损失原本有价值的借杀。还会防无懈。 | 再要求实际配对执行借刀。首轮已交出的武器不能再拿一次；首轮出的杀与取牌须先扣除，第二轮再判断出杀/交刀分支。 |

## 3. 档位组合比孤立档位更重要

### 决斗：三档经常是核心，一级不是无条件好

无忧只有一张杀时，对原目标和追加目标依次决斗，可能把自己耗空并受伤。若命中三档，目标先出杀而不可响应，通常不进入双方耗杀循环，同一追加目标的价值会明显上升。支付前必须把“只命中一档”和“同时命中三档”的不同后果按概率分开；翻牌后可以放弃原本不安全的追加。

按用户补充，将敌方公开手牌数作为一档追加目标的主要筛选和排序依据，1～2 张手牌进入可尝试区间，而不是把“未命中三档的决斗”一律判危险。以下用于没有特殊响应规则的普通决斗；无忧可用杀要检查实际响应合法性，并按结算顺序更新剩余数量。

| 候选敌方的手牌数 | 一档决策条件 |
| --- | --- |
| 0 | 优先评估追加。排除已知无手牌也能出杀/免伤的能力后，目标先响应且无法出杀，通常可直接造成伤害，无忧自己没有杀也不因此拒绝。空手目标的二档取牌收益为零，不重复加取牌分。 |
| 1 | 积极评估。若轮到它时无忧还可响应至少一张杀，普通规则下通常能接住唯一一次对抗；若自己无杀，则比较对方持杀的公开信息先验、自身受伤风险和其余收益，不直接当作安全目标。 |
| 2 | 可尝试，阈值比一手牌更谨慎。自己剩一张杀时，对方两张都能作杀才可能在正常连续响应下压过自己；自己剩两张合法杀则更稳。若自己无杀、低血且缺救援，通常不为普通增伤冒险。 |
| 3 及以上 | 降低优先级，但不硬性排除。自己杀足够、存在重要斩杀机会或能开启三档时，仍应进入收益比较。 |

手牌数只是公开的响应能力线索，不等于杀的确切数量。对方可将其他牌转杀、用装备/特殊牌区响应或改变每次响应张数时，必须调整估计。即使候选只有一手牌，也不能为原目标、追加目标、第二轮分别重复使用无忧同一张杀。

翻出三档并决定开启不可响应后，普通目标的手牌数不再决定它能否接决斗；此时主要比较伤害、斩杀、免伤、二档可取牌数与友敌关系。发现零手牌敌人意味着追加分支有真实收益，不等于立即花末忆：支付层仍比较翻牌概率、库存和储备成本。

无忧在决斗中打出的杀属于响应失牌，按当前忆机制可能补充对应花色忆；它依然消耗真实手牌，不能用加忆把防御成本抹掉。火攻弃牌也有类似加忆路径。新模型需同步更新手牌和忆。

### 过拆/顺手：原牌移动、二档取牌、第二轮顺序更新

假设敌人仅两张手牌、无装备判定：过拆第一次拆一张，二档拿剩余一张，第二轮已经没牌可拆取。假设敌人牌足够，则多轮拆取都可以实际发生。给队友拆负面判定是好事，但自动再拿队友一张手牌可能抵消收益；二档可单独不选。

### 铁索：四档可坏，二加四又可能好

原目标是“连敌、解友”时，第二轮翻回去会破坏原计划。原目标是若干有手牌敌人、连环状态并不重要时，两轮取牌可能足以补偿状态收益消失。只检查第二轮连环的独立分数，会漏掉该分支；只检查两轮取牌，也会高估友方重新被连上的风险。

### 火攻：不造成伤害也可能有二档收益

缺匹配弃牌不代表追还一定没价值。正常火攻结束后仍可能取敌方一手；追加目标后可取更多目标。反过来，二档提前拿空目标，会让四档火攻失去展示牌，不能同时算“拿空”和“再次正常火攻”。

### 桃园和五谷：不能合并成一种全场摸牌模型

桃园只对受伤目标实际结算，第二轮可能人数更少。五谷在正常结算中先发一张，再取一张，原本空手的敌人也可能成为有效取牌目标；其选择顺序、公开牌池质量也重要。两者的二档、四档收益来源不同。

### 借刀：两层目标与特殊强命

借刀不等同于普通单目标伤害牌。持武器者是原锦囊目标，被要求吃杀者是配对的辅助目标；新增持刀者还需要一个合法的出杀对象。原生有 `addExtraTarget` 补选路径，但存在索引错位反例，见下方待修问题。追还二档通常从持刀者手中取牌，不能把被借刀杀的对象再计一份。

三档会让持刀者不能执行借刀要求的出杀，直接进入无忧获得其可获得武器的分支。若原本想借敌人的刀杀另一敌人，拿武器未必比那次杀更好；若目的是拆走强力武器，则三档可能很有价值。该子杀也不能继承父锦囊的二档/三档/四档并重复计算。

四档在第一轮已经拿走武器后，不能再算拿到第二把同一武器；如果第一轮出了杀，第二轮还可能再次要求出杀或交武器。原生牌内容不重新检查最初“有武器”的选目标条件，不能因为武器已拿走就认定第二轮必定整个跳过。需要保持两层目标配对和实际剩余装备。

| 3 | 98.4375% | 65.625% | 9.375% | 0 |
| 4 | 100% | 98.4375% | 65.625% | 9.375% |

因此，群体牌付四色的常见理由可能是稳定获得二档及较大概率三档，而不是单赌 9.375% 的四档。正常 AOE 一档无目标，只有一个花色有忆时即使付出也没有对应升级收益，应保留。四花色各一枚和总共只有一枚忆是完全不同的局面。

对每个可支付花色集合，枚举 `m=0..k` 的结果；每个结果只在已解锁、实际合法的选项中选择净收益最高的组合。把各结果加权，再扣支付后储备损失、恍惚防御机会与风险。余量多会降低边际成本，但不会把友死、资敌、空目标或牌已拿空变成正收益。

## 5. 风险、可达性与后续实现验收条件

用户既定偏好保持：有可靠获胜机会时可接受友伤甚至友死；只换普通敌人却牺牲队友通常不做；击杀敌人并让队友非致命受伤可以考虑；同一路径交换两敌一友可计算，不能只按绝对禁友伤处理。结算顺序和真实胜负条件优先于简单人数加减。

每张牌至少需要以下见证，避免新牌名进名单后实际上仍永远拒绝：

1. 有合法目标、库存、足够忆且升级增量为正时，支付分支确实可达。
2. 只有末忆且一档无收益、追加友死、无可取牌或第二轮无效果时，能正确保留/取消。
3. 二档开启后改变第一轮库存，四档用新库存，不重复获得同一张牌。
4. 三档按本牌语义处理，明确防无懈、限制响应与不能绕过的被动效果。
5. 一项负收益不会屏蔽已解锁的其他正收益项；判断未知信息时不能把所有常见局面全部变成永久拒绝。
6. 本人用牌、神落绯等外部强制用牌分开处理：追还仍可触发，不能误加不满足条件的朦胧重铸收益。

本轮只形成分析与规则依据。没有修改 AI，也没有新增完整实战。上表的防无懈价值属于完整建模要求，不能误读为现有 v3 已实现所有普通锦囊的无懈概率。对应的引擎语义复核与对抗分析保存在 `artifacts/wuyou-ai-card-analysis/`。
